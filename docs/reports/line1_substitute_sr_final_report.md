## 1. 摘要

### 1.1 一句话结论

在本数据生成器与标准退化强度（σ_K=11.0、σ_n=1.22e-4）下，**中等复杂度物理先验对主指标（高频掩膜内误差 ε_high^mask）的平均增益未获跨训练种子稳健确认**：图像先验 **B** 在同分布测试集上 3/4 个训练种子优于无先验基线 **A**，但种子级置信区间横跨零，故判定为「等效（种子级）」；参数先验 **C** 与 A、B 的对比因存在显著正/显著负并存的「反向对」，判定为「种子敏感、不可判定」。

**C 的价值集中在下游物理量与不确定性**：C 的次指标发射度相对误差 ε_z 在 4 个训练种子一致约为 A/B 的 **1/2**（均值 0.011–0.012 vs 0.021–0.024，来源 `studies/line1_substitute_sr/results/summary/EXP-02_summary/seed{0..3}/summary_test_id.json` → `metrics.<scheme>.e_eps_z.mean`）；且 C 在噪声重实现下的预测离散度 4 种子一致最低（A/B 的 1/2–1/4，来源 `studies/line1_substitute_sr/results/run/EXP-02_<scheme>_seed<s>_run1_D2/metrics.csv` split=exp08）。

**一票否决**：B、C 两方案在 4 个种子均判「局部失效」（失效概率 P_F=0，未触发 20% 触发率上限），**无方案级否决**（来源 `studies/line1_substitute_sr/results/summary/EXP-02_summary/seed{0..3}/summary_test_id.json` → `one_veto.<scheme>.verdict`）。

### 1.2 主指标（ε_high^mask）三分类判定

同分布留出子集（1000 样本/方案/训练种子），逐种子样本级配对差 bootstrap 95% 置信区间 + Wilcoxon + Holm 校正的三分类判定。**三分类的含义**：显著正 = 后一方显著优于前者；显著负 = 后一方显著劣于前者；等效 = 置信区间横跨零，证据不足以区分（这是合法的"无差异"判定，不等于"无增益"）。4 个训练种子重判结果（来源 `studies/line1_substitute_sr/results/summary/EXP-02_summary/seed{0..3}/summary_test_id.json` → `three_class.*`；重判见 `studies/line1_substitute_sr/results/summary/EXP-02_summary/logs/g2_rejudge.py`）：

| 对比 | seed0 | seed1 | seed2 | seed3 | 4 种子判定 |
|---|---|---|---|---|---|
| **A − B** | 等效 | 显著正（B 优） | 显著正（B 优） | 显著正（B 优） | **等效（种子级）** |
| **A − C** | 显著正（C 优） | 显著负（A 优） | 显著正（C 优） | 显著正（C 优） | **种子敏感、不可判定** |
| **B − C** | 显著正（C 优） | 显著负（B 优） | 显著正（C 优） | 等效 | **种子敏感、不可判定** |

判定依据的关键数字（逐种子置信区间见 §4.1；来自 `seed{s}/summary_test_id.json` → `three_class.M_A_minus_M_{B,C}.ci95`）：

- **A − B**：4 个训练种子配对差均值 {+3e-6, +3.0e-4, +6.8e-4, +4.3e-4}，种子级均值 +3.53e-4，t(3) 95% 置信区间 = **[−9.4e-5, +8.0e-4]（含零）** → 按"多数方向一致但种子级区间含零"规则由「多数正」降级为「等效（种子级）」。作为对照的合并（concatenated, n=4000）bootstrap 区间 = [+3.3e-4, +3.8e-4]（**不含零**）——两者矛盾正是 §4.3 披露的「伪重复」现象。
- **A − C**：种子级均值 +3.19e-4，t(3) 95% 区间 = **[−2.8e-4, +9.2e-4]**；逐种子含反向对（seed1 显著负 vs 其余显著正）→ 兜底判"不可判定"。
- **B − C**：种子级均值 −3.4e-5，t(3) 95% 区间 = **[−4.6e-4, +4.0e-4]**；逐种子含反向对 → 兜底判"不可判定"。

### 1.3 次指标（ε_z）与物理量水平

在同分布测试集上各方案 4 训练种子合并（n=4000/方案，来源 `studies/line1_substitute_sr/results/summary/EXP-02_summary/pooled_test_id_metrics.json`），物理量相对误差：

| 方案 | ε_z（发射度） | ε_z 跨种子范围 | 说明 |
|---|---|---|---|
| A | 0.02186 ± 0.03296 | 0.021–0.023 | 基线 |
| B | 0.02356 ± 0.03458 | 0.022–0.024 | 图像先验，ε_z 略高于 A |
| **C** | **0.01140 ± 0.01209** | **0.011–0.012** | **约为 A/B 的 1/2** |

### 1.4 一票否决

B、C 两方案在 4 个训练种子上「一票否决」判定均为「局部失效」（P_F = 0，n_triggered = 0），未触发方案级否决（来源 `seed{0..3}/summary_test_id.json` → `one_veto`）。含义：没有任何训练种子出现"图像指标更好但物理指标系统性恶化超过阈值"的方案级失败。

### 1.5 适用条件与核心数据

- **适用条件**：本结论在「标准退化 + 第一档物理复杂度 + 同分布测试集」范围内成立；参数留出带（|γ| ∈ [0.3, 0.4]）与强退化档（强模糊/高噪声）的适用性见第 7 章外部效度证据。
- **先验增益与置信区间**：主指标上 A−B 种子级 [−9.4e-5, +8.0e-4]（等效）；A−C、B−C 种子敏感不可判定。次指标 ε_z 上 C 稳定占优（约 1/2），4 种子一致。
- **出口结论**：条件 1（同分布显著正增益）不满足 → 以阴性/等效结论完成出口（详见第 7 章）。

## 2. 实验设置

### 2.1 数据规模

数据版本 `v1`（来源 `studies/line1_substitute_sr/data/v1/manifest.json` → `splits.<split>.count`）：

| 划分 | 样本数 | 采样模式 |
|---|---|---|
| 训练 | 20,000 | 参数留出带外 |
| 验证 | 2,000 | 参数留出带外 |
| 同分布测试集 | 1,000 | 带外（同分布留出，主判定） |
| 留出测试集 | 1,000 | 带内（与同分布 1:1，必报不合并） |
| 极端参数集 | 500 | 极端参数（豁免掩膜；**未执行外推评估**） |

master_seed = 20260825；种子派生按 8 分支 SeedSequence（`manifest.json` → `seed_derivation`）。参数留出带 |γ| ∈ [0.3, 0.4]（`manifest.json` → `gamma_block`），同分布/留出测试集分别取带外/带内。

### 2.2 物理生成（第一档复杂度参数范围）

生成函数从「基础密度 + 压缩折叠映射」生成高分辨率相空间图像 H（256×256，z,δ ∈ [−1,1]，像素中心采样），不直接绘制目标形状。核心采样参数范围（来源 `docs/specs/20_physics_generator_spec.md`，上海软 X 射线自由电子激光经典推算值）：

| 参数 | 范围 | 分布 | 物理含义 |
|---|---|---|---|
| σ_z | [0.30, 0.70] | 均匀 | 压缩后束团纵向长度 |
| n | [1, 3] | 均匀 | 电流剖面指数（高斯→近平顶） |
| η | [−0.3, 0.3] | 均匀 | 头尾不对称 |
| b_0 | [0.04, 0.09] | 均匀 | slice 相对能散 |
| a_1 | [−0.75,−0.35] ∪ [0.35, 0.75] | 幅度均匀、符号等概率 | 关联能散（chirp） |
| α | 由 C=1+a_1·α 导出，|α|≤3 | 随 C、a_1 联合 | 压缩器 R_56 |
| a_2 | [−0.10, 0.10] | 均匀 | 二阶 chirp |
| β | [−2.0,−0.9] ∪ [0.9, 2.0] | 幅度均匀、符号等概率 | 二阶折叠 T_566 |
| a_3 | [−0.05, 0.05] | 均匀 | 三阶 S 形 |
| γ | −sign(β)·[0.1, 0.6] | 幅度均匀、符号与 β 相反 | 三阶精细卷曲 U_5666 |
| b_1 | [−0.10, 0.20] | 均匀 | 局部能量厚度变化 |

联合约束：压缩因子三态（欠压缩/最佳/过压缩各约 1/3）、精细结构窗口（2.5 px < w_fine/Δ_px ≤ 0.8·σ_K）、有效性掩膜白名单。第一档复杂度不含相干同步辐射（CSR）、halo（属更高复杂度档，不进入第一版主实验）。本次实验光滑渲染宽度 σ_smooth,H=0.125×w_fine（逐样本，见 `docs/specs/20_physics_generator_spec.md`）。

### 2.3 退化协议

退化函数依序执行（来源 `studies/line1_substitute_sr/results/run/EXP-02_A_seed0_run1_D2/config.yaml` → `degradation` / `calibration`）：

1. **模糊**：各向同性高斯核，σ_K = 11.0（以 H 像素为单位）。
2. **下采样**：256 → 64，r = 4，**r×r 块求和**（保总强度）。
3. **噪声**：加性高斯噪声 σ_n = 1.22e-4，非负截断 `L = max(0, L_clean + n)`。

退化强度等级：弱退化（σ_K 标定对比档）、标准（主实验档）；强退化不设独立等级，由正交配置替代——强模糊（σ_K=22.0，2×标准）、高噪声（σ_n=1.133e-3，9.29×标准）。高噪声档生成前通过可行性校验（批量中位数信噪比 SNR_main=2 恰好成立）。信噪比元数据：SNR := mean(L_clean)/σ_n；精细结构「不可清楚分辨」判据 SNR_hf < 0.1（见 `docs/specs/30_degradation_spec.md`）。

### 2.4 三方案架构与参数量

三方案共享同一残差 U-Net 主干（5 级、通道 48/96/192/384/384、瓶颈封顶 384、C₀=48、num_residual_blocks=2）、同一损失、同一训练配置（公平性约束，来源 `config.yaml` → `network`；参数量来源 `studies/line1_substitute_sr/results/summary/EXP-02_summary/stage_report.md` §7.2）：

| 方案 | 结构 | 参数量 |
|---|---|---|
| A（无先验 baseline） | Ĥ_A = NonNeg(L_up + G0(L_up)) | 24.26M |
| B（图像先验 + 残差，early fusion） | Ĥ_B = NonNeg(P2 + G1(L_up, P2)) | 24.26M |
| C（参数先验 + FiLM） | Ĥ_C = NonNeg(L_up + G2(L_up \| c_prior)) | 24.43M（+0.70%） |

图像先验 P2 为「低阶结构估计」（σ_smooth,P = 15×σ_smooth,H，全频带 L1 比值 0.5288 落于 (0.2, 0.9] 且近 0.55 锚点）。先验不含高频精细结构参数（防泄漏铁律）。所有输出经 Softplus 激活并复位到工作尺度，评估时除以 work_scale S=N²=65536（双空间契约）。

### 2.5 训练配置

AdamW（lr=3e-4、wd=1e-4）、batch 16/卡（双卡 DDP 数据并行，等效 batch=32）、max_steps=50,000、早停 patience=10、min_step_fraction=0.5、val_interval=2,000；空域-频域混合损失 L_total = L_space + λ·L_spec，λ=1.0 冻结（**为什么需要频域损失**：像素 L1 在低频区梯度大、高频区小，网络会被"诱导"先拟合低频、放弃高频；频域损失直接约束高频带能量，强迫网络恢复压缩折叠脊、峰值尖峰这些精细结构）；精度 fp32（本机 Turing CC 7.5 不支持 bf16）（来源 `config.yaml` → `training` / `gpu`）。

## 3. 主实验结果

主指标与物理量均在总强度归一化到 1 后计算。下表为同分布测试集上各方案 4 训练种子合并（n=4000/方案）的均值 ± 标准差（来源 `studies/line1_substitute_sr/results/summary/EXP-02_summary/pooled_test_id_metrics.json`）。

### 3.1 图像质量

| 方案 | PSNR (dB) | MAE | MSE | SSIM（感知版 ssim_vis） |
|---|---|---|---|---|
| A | 115.98 ± 2.90 | 4.58e-07 | 3.22e-12 | 0.99630 |
| B | 117.80 ± 2.99 | 3.81e-07 | 2.13e-12 | 0.99684 |
| C | 120.72 ± 2.75 | 2.64e-07 | 1.05e-12 | 0.99885 |

> **注意**：PSNR/SSIM 在总强度归一化（图像总和 = 1，像素量级 ≈ 1e-5）后计算，故 PSNR 绝对值异常高（115–120 dB），数值上仅用于方案间相对比较，不宜作绝对质量解读。三种方案的原始 SSIM 均饱和（≈0.99999），因此用感知一致性指标 ssim_vis（A 0.9963 / B 0.9968 / C 0.9989）区分。

### 3.2 物理一致性（相对误差）

| 方案 | ε_z（发射度） | σ_z | σ_δ | h_eff | I_peak |
|---|---|---|---|---|---|
| A | 0.02186 ± 0.03296 | 0.01046 ± 0.01399 | 0.00771 ± 0.00811 | 0.0993 ± 0.6069 | 0.00609 ± 0.00488 |
| B | 0.02356 ± 0.03458 | 0.01127 ± 0.01316 | 0.00831 ± 0.00905 | 0.0930 ± 0.6908 | 0.00628 ± 0.00500 |
| **C** | **0.01140 ± 0.01209** | **0.00646 ± 0.00602** | **0.00499 ± 0.00463** | **0.0527 ± 0.3014** | **0.00457 ± 0.00362** |

**C 在全部五个物理量上的相对误差均低于 A/B**，其中 ε_z 稳定约为 A/B 的 1/2，σ_z / σ_δ / I_peak 约为 A/B 的 0.6–0.8 倍，h_eff（有效发射度）显著低于 A/B。这是「先验提高下游物理量精度」的核心定量证据。

> **h_eff 误差分布说明**：h_eff 相对误差的标准差（0.30–0.69）远大于均值（0.05–0.10），属重尾分布（少数样本 h_eff 接近零导致相对误差极端放大）；均值±标准差对该指标代表性弱，方案对比应侧重中位数或秩检验（h_eff 未纳入主/次指标判定，仅作补充报告）。

### 3.3 精细结构恢复

| 方案 | ε_high^mask（主指标） | ε_high^DoG（高频误差） | ε_peak（局部峰值） | R_E 中位数 |
|---|---|---|---|---|
| A | 0.001573 ± 0.001242 | 0.002268 ± 0.001233 | 0.000411 | 1.69 |
| B | 0.001220 ± 0.001188 | 0.001748 ± 0.001009 | 0.000327 | 1.62 |
| C | 0.001254 ± 0.000674 | 0.001396 ± 0.000600 | 0.000221 | 1.84 |

主指标 ε_high^mask 上 A−B、A−C 的关系呈「种子敏感」形态（见 §3.4 与 §4.1）；高频误差 ε_high^DoG 与局部峰值误差 ε_peak 上 C 均最低。R_E（锐化守卫）三方案均远低于阈值 10（中位数为 1.6–1.8，见 §5.3）。

### 3.4 跨种子稳定性（主指标）

主指标逐种子均值（来源 `studies/line1_substitute_sr/results/summary/EXP-02_summary/seed{0..3}/summary_test_id.json` → `metrics.<scheme>.e_high_mask.mean`）：

| 方案 | seed0 | seed1 | seed2 | seed3 | 跨种子漂移 |
|---|---|---|---|---|---|
| A | 0.001257 | 0.001484 | 0.001800 | 0.001750 | +43% |
| B | 0.001255 | 0.001182 | 0.001122 | 0.001323 | +18% |
| C | 0.001061 | 0.001600 | 0.001014 | 0.001341 | +58% |

### 4.3 合并置信区间的「伪重复」披露（必读）

按报告义务需同时给出逐种子与合并（concatenated）置信区间。合并区间（n=4000，样本级配对差池化）：

| 对比 | 合并 CI（描述量） | 种子级 t-CI（判定依据） |
|---|---|---|
| A − B | [+3.3e-4, +3.8e-4]（**不含零**） | [−9.4e-5, +8.0e-4]（**含零**） |
| A − C | [+2.9e-4, +3.5e-4]（不含零） | [−2.8e-4, +9.2e-4]（含零） |
| B − C | [−5.9e-5, −6.9e-6]（**不含零**，全负） | [−4.6e-4, +4.0e-4]（含零） |

**关键披露**：合并区间把不同训练种子的样本当作"独立同分布"，在存在种子随机效应时会产生「伪重复」，覆盖率可跌至 ~5%（模拟证据见 `studies/line1_substitute_sr/results/summary/EXP-02_summary/consultation/g2_seed_inconsistency.md` §2.4：当种子级随机效应 σ_τ=2.2e-4、样本级 σ=1.7e-4、n=1000/种子时，合并区间对零效应的覆盖率仅 4.9–5.1%，而种子级 t-CI 为 95%）。因此 A − B 的合并区间 [+3.3e-4, +3.8e-4]「稳定为正」的假象**不可作判定依据**；B − C 的合并区间全为负同样受伪重复影响、与种子级 t-CI（含零）矛盾，**均不可作判定依据**。判定以逐种子 verdict + 种子级 t-CI 为准（含零 → 等效）。本报告的判定（§4.1）采用种子级口径，合并区间仅作描述量披露。

> **通俗解释（为什么"合并样本"是陷阱）**：想象请了两位水平相近的厨师按同一份菜谱做菜，第一位说"C 方案最好吃"，第二位说"C 方案最难吃"。如果我把两人的每一次品尝记录拼在一起算总体评价，会得到某个"平均结论"——但这个结论是假的，因为两人确实来自不同的"口味偏好"，拼在一起掩盖了真实的分歧。合并区间就是犯了同样的错：把不同种子得到的、本就不同的分布当成同一总体抽样，区间被错误地变窄、变乐观。所以判定必须"每人单独看"（逐种子 verdict），不能"拼起来看"。

### 4.5 方案 B 与 C 的形式差异（条件式）

B（图像先验 + 残差，early fusion）与 C（参数先验 + FiLM）的差异是**三种增强方式（信息形式 + 注入机制 + 信息保真度）的综合**，不能单独归因于某一种。基于数据可观察到的差异：

- **主指标**：B 在退化档（强模糊/高噪声）4/4 种子稳健优于 A（A−B 不反转），而 C 在退化档反转或种子敏感——说明**图像先验（同网格、物理空间对齐、残差锚定）在退化强度变化时更稳健**；参数先验的 FiLM 调制在极端退化下可能失效。
- **次指标与不确定性**：C 在 ε_z（约 1/2）与噪声重实现离散度（1/2–1/4）上稳定占优，且训练损失最低——**参数先验能更精确地约束下游物理矩与跨实现稳定性**。

由于三方案参数量差（A/B 24.26M、C 24.43M，+0.70%）远低于 10% 公平阈值，且频段分解证据（高频误差 ε_high^DoG：C 0.0014 < B 0.0017 < A 0.0023）支持，可作形式层面的观察性表述；但**不预设「参数先验必然更稳定」**——事实上主指标上 C 恰恰最不稳定（种子敏感 + 退化档反转）。

### 4.6 留出测试集（参数留出带内）三分类与一票否决（必报）

留出测试集为 γ 块内（|γ| ∈ [0.3, 0.4]）的 1:1 配对样本，属参数留出带邻域外推任务，按预注册约定**必报、不并入主判定**（来源 `studies/line1_substitute_sr/results/summary/EXP-02_summary/seed{0..3}/summary_test_pb.json` → `three_class` / `one_veto`）：

| 对比 | seed0 | seed1 | seed2 | seed3 |
|---|---|---|---|---|
| **A − B** | 等效 | 正 [+1.9e-4, +2.8e-4] | 正 [+6.1e-4, +7.0e-4] | 正 [+3.7e-4, +4.7e-4] |
| **A − C** | 正 [+1.7e-4, +2.9e-4] | 负 [−1.6e-4, −4.9e-5] | 正 [+7.6e-4, +8.9e-4] | 正 [+4.0e-4, +5.0e-4] |

### 5.4 机制分析：尺度锚定与信息论

高频幻觉（网络在低频锚定误差、依训练分布「脑补」高频纹理）的机制可参考 **Scale Anchoring 与频谱偏差** 理论（文献 wang2026 *Breaking Scale Anchoring*，ICLR 2026，归档于 `docs/wang2026_breaking-scale-anchoring_2512.05132v2.pdf`）：

- **(i) 尺度锚定与频谱偏差**：网络倾向于用低频信息锚定重建误差，并按训练分布的统计规律「脑补」高频纹理。本实验的残差图（图 5）沿压缩折叠呈对角条状结构、且高频误差显著大于全图级误差，正是这一机制的体现——高频精细结构（压缩折叠脊、电流尖峰）是网络最容易「脑补」而非准确恢复的区域。
- **(ii) 信息论论证**：退化（模糊 + 下采样 + 噪声）使高频成分落入噪声底以下，先验（图像先验或参数先验）作为「噪声底以下缺失信息」的条件锚点，构成方案 B/C 必要性的来源——先验在此提供高频缺失信息，从而帮助网络在有强噪声/强模糊时约束重建。

**两条限定（必须同时写明）**：

- (a) 本项目为**配对监督**超分，不同于该论文的零样本设定——方案 A 可经训练分布内的统计耦合推断部分高频成分（零学习基线检查显示 A 相对直接上采样已降误差 93–95%），故「先验必要性」是与「网络统计推断」叠加的增量性论证，而非替代性论证。
- (b) 本项目退化中的**高斯模糊为软衰减而非严格带限**、且**正向模型完全已知**——因此失效边界应表述为「**低于噪声底的成分不可恢复**」，而非严格 Nyquist 截断。

### 5.5 幻觉的边界读法

遵循「物理指标优先于图像指标 + 一票否决」规则：图像质量（PSNR/SSIM）三方案都极高且接近，但物理指标（ε_z 等）C 明显更优。一票否决判定：B、C 两方案 4 种子均判「局部失效」（P_F=0，n_triggered=0，未达 20% 触发率上限），**无方案级否决**——即在方案聚合层面，未出现"图像指标更好但物理指标系统性恶化超过阈值"的失败模式。幻觉风险的直接证据是残差图中的折叠恢复不足（图 5），它体现在高频误差而非物理量上；物理量层面 C 反而最稳。

## 6. 结论与局限性

### 6.1 命题 (a)：先验是否显著降低超分辨率逆问题的不确定性

**支持证据 = 噪声重实现敏感度**：同一高分辨率真值 H 的 8 个独立噪声实现下，C 的预测跨实现离散度 4 种子一致最低（0.000073–0.000111，为 A/B 的 1/2–1/4，来源 `studies/line1_substitute_sr/results/run/EXP-02_<scheme>_seed{0..3}_run1_D2/metrics.csv` split=exp08）。**结论**：先验（尤其是参数先验 C）显著降低了受噪声重实现扰动的预测不确定性——**命题 (a) 成立**。此为推理级证据（复用主实验权重、不重训）。

### 6.2 命题 (b)：先验是否提高精细结构恢复的物理一致性

**支持证据 = 物理级指标 + 三分类判定**：

- 次指标 ε_z：C 4 种子一致约为 A/B 的 1/2（0.011–0.012 vs 0.021–0.024），逐样本配对差三分类均为显著正（Wilcoxon p < 1e-30）。**物理一致性上 C 稳定占优**。
- 主指标 ε_high^mask：A−B = 等效（种子级），A−C / B−C = 种子敏感不可判定——**主指标像素误差层面，先验优势未获跨种子稳健确认**。
- 精细结构高频误差 / 局部峰值误差：C 均最低，B 次之，A 最高。

**结论（命题 b 需分两层）**：主指标（像素级高频误差）上，先验优势**种子敏感**（B 稳健略优但不显著、C 不稳定）；物理量级上，先验（尤其 C）**稳定提高物理一致性**。因此「先验提高精细结构恢复的物理一致性」在**物理量层面成立**，在**主指标像素误差层面不稳健**。

### 6.3 三分类结论与阴性/等效模板

按项目预注册的阴性/等效结论模板如实填写（在本数据生成器与退化强度下）：

> 在本数据生成器与标准退化强度（σ_K=11.0、σ_n=1.22e-4）下，中等复杂度物理先验（B 图像先验、C 参数先验）对**主指标 ε_high^mask 的平均增益为**：A − B = **等效（种子级，CI [−9.4e-5, +8.0e-4]）**，A − C = **种子敏感、不可判定**，B − C = **种子敏感、不可判定**；**对次指标 ε_z 的平均增益为**：C 相对 A/B 稳定约为 1/2（4 种子一致显著正）。失效（主指标层面不稳健）集中于训练种子变化与极端退化档（σ_K=22 强模糊、σ_n=1.133e-3 高噪声）；该结论对出口决策同样有效（见第 7 章）。

### 6.4 局限性

1. **未包含物理损失**：训练损失为空域-频域混合损失（λ=1.0 冻结），未把 ε_z 等物理矩直接作为损失项——因此 C 在物理量上的优势是网络隐式学到的，而非损失显式优化的结果。
2. **未使用估计先验**：第一版先验由生成器理想给出图像先验/参数先验，未研究「估计先验（从低分辨率观测估计先验）」方案。
3. **外推评估未执行**：更高复杂度级别与极端参数外推未执行；极端参数数据（500 样本）**已生成并保留**于 `studies/line1_substitute_sr/data/v1/test_ood.h5`（含参数留出带豁免样本）。泛化裕度证据标记为「证据缺失」，不以同分布结果充抵（见第 7 章外部效度证据规则）。
4. **增益—退化曲线仅两点方向判定**：第一版用标准 vs 强退化档做每轴两点方向性对比，未做单调性判定（完整曲线属分级扫描）。
5. **主指标在种子层面的敏感性**：C 的 FiLM 调制对初始化敏感（不同种子收敛到不同盆地），主指标跨种子翻转反映了这一点；本报告以 4 个训练种子为上限，不再扩种子。

| 加性高斯噪声 + 零值截断（见退化协议规范） | 真实探测器散粒噪声（Poisson）+ 读出噪声 + 暗电流/增益非均匀/饱和/量化/坏像素 | **低估**亮区统计噪声（高斯 vs 泊松）与探测器效应；截断引入低密度区正向偏置 |
| 块求和下采样 r=4（见退化协议规范） | 真实像素响应接近积分 | **近似**（接近，细节未知） |
| 高斯模糊软衰减、正向模型完全已知 | 真实正向模型隐含未知偏差 | **乐观**：本项目正向模型完全已知，真实场景需估计退化 → 可能高估 |
| σ_smooth,H=0.125×w_fine 光滑渲染 | 真实束流相空间连续、无渲染光滑 | **近似**（为避免数值伪影引入，由高频能量守卫约束） |

**证据 4：泛化裕度**

- 高阶/极端参数外推**未执行** → 泛化裕度证据标注「**证据缺失**」，**不以同分布结果充抵**（见出口决策的外部效度证据规则）。极端参数数据（`studies/line1_substitute_sr/data/v1/test_ood.h5`，500 样本，极端参数、参数留出带豁免、含 62 个带内样本）已生成并保留，可在后续阶段直接评估。

### 7.4 出口与后续建议

- **B（图像先验）**：主指标稳健（同分布 3/4 种子优且种子级等效、退化档 4/4 优），是「先验有稳健正效应」的最接近候选，但未达条件 1 的「显著正」门槛（种子级置信区间含零）。
- **C（参数先验）**：主指标种子敏感 + 退化档反转，稳健性不足；但次指标（ε_z 1/2）与不确定性（噪声重实现 1/2–1/4）稳定占优——**C 的价值在下游物理量与不确定性，而非主指标像素误差**。若要提拔 C，需先解决其 FiLM 训练稳定性（属换法提案，需用户裁决）。
