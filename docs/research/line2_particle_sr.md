## 研究问题（主线，2026-09-13 用户确定）

同一束流在 4D 横向相空间 `(x, x′, y, y′)` 的**六张两两投影热力图**：低粒子数（N_low）版本 → 神经网络 → 与高粒子数（N_high = 2e5）版本在同等分辨率（128×128）下的六张图统计一致。一句话定义：**「1万粒子的 6 张图 + 网络 → 20万粒子的 6 张图」**。

**Phase 划分**：
- **Phase 1（当前焦点）**：图像接口的纯放大——输入输出同分辨率（128×128 → 128×128），只有 N 变；单站对（FODO 前/后两站）起步，一次只动一个变量（N）；
- **Phase 2**：束流接口（粒子云）+ 多站点传输闭环（H7 完整形态）+ 接口对比（H3b）；
- **Phase 3**：分辨率与比值扩展（L8）。

### 本质目标（2026-09-13 用户定调）：模拟加速 = 粒子数放大

终极目的**不是把图放大，而是让模拟更快**：低 N 便宜模拟 + 网络 ≈ 高 N 模拟。形式化：**学习式模拟放大 / 方差缩减**。目标修正随之确立：**真值 = 高 N 收敛密度**——低 N 输入下的"过平滑"是正确行为（Poisson 涨落是被去除的对象）；唯一要防的失败模式是丢掉真实密度里的真细结构（H8，对高 N 真值可测量）。头牌指标：**等效放大因子 N_eff**——「N_low + 网络」质量 ≈ 「N_eff 裸模拟」质量（定义预注册于 `20_metrics_spec` [S3]）。

**放大上限的诚实声明（2026-09-14 修订）**：锚点束只有 2×10⁵ 颗粒子 → Phase 1 的 N_high = 2e5；**可验证放大上限 = 10×**（1e4 → 1e5，N_eff 报告域 [1e3, 1e5]）——参照自身噪声地板（1e5 档独立子样本配对 M1 差/√2）使 >1e5 部分不可分辨，20× 为锚点规模给出的叙事上限。bootstrap 有放回重采样不产生新信息；"100万粒子真值"需更大初始文件或密度拟合采样（循环性风险），挂起待议。

### 输出语义（2026-09-13 用户确认；Phase 2 生效）

Phase 2 主模型的输出 = **一份合成 4D 束团**（M 颗粒子 + 等权），六张 128×128 投影是它经可微渲染生成的派生品——网络的本职是「六投影 → 4D 束流重建器」，图像超分只是这个任务在图像空间的投影。三个精确化：(1) 输出是「与六投影相容的最可信密度代表」，不是真粒子本身（可识别性缺口；验证永远统计级）；(2) M 是密度载体与真 N 解耦；(3) Phase 1 输出仍是六张图（图像接口）。研究身份：**学习式单次 4D 束流重建**——传统 quad-scan 层析需多次改变光学设置，此处一次测量出 4D。

**为什么要有 Phase 2 束流接口**：(1) 跨投影相容由构造保证——幻觉结构必须同时活过六次渲染与传输检验；(2) 六投影联合约束同一隐对象；(3) 输出可传输/可算 ε_4D 与晕占比/任意分辨率重渲染/可重采样；(4) 验证走出六张图边界。诚实对立面：若终端只要更好的投影图，图像接口足够；Phase 1 先行即为对冲。

### 数据模型（2026-09-13 定案；2026-09-14 束群定案）

- **束源：真实 SDDS 粒子，唯一束源**——`injector.sdds` 直接导入（`sdds` 包，p=βγ 契约），**不从 Twiss 重新生成束流**；Twiss-Gaussian 受控档移除（H6 挂起）；解析真值不可得，训练目标 = 2e5 全量直方图（残余 label noise 可接受，`20_metrics_spec` [S2] 有参照噪声语义声明）。
- **束群（B1 定案，2026-09-14 用户批准）**：束 i = 锚点全量表经束级抖动线性变换 + 共同 FODO 的实现（L = 1000，train 700 / val 150 / test 150；抖动 = 前置薄透镜 ±5%、踢角 ±10 µrad、漂移 495–505 mm，分布预注册于 `10` [S3]；束 0 为无抖动基准束）。**推广域声明：锚点分布的线性变换邻域**；真实前端晶格跨域泛化属 Phase 2。
- **Ocelot 角色：晶格传输引擎**（P1 线性；Phase 1 lattice 定死：Ocelot 原生 FODO，n_cells = 2、μ = 75°/cell、半 cell 漂移 2.5 m——`10` [S3]）。依赖：`ocelot` + `sdds` 入 `environment.yml`。
- **配对机制**：A = 同一束流表随机子采样（A ⊂ B）；传输确定性 ⇒ 先传输后子采样可交换：跟踪一次 B → B1，A/A1 取各站子采样；子采样统一网格 = 五档 {1e3, 3e3, 1e4, 3e4, 1e5} × k=20（训练消费三档，曲线消费五档；`10` [S2]/[S5]）。
- **训练对**：输入 = N_low 六张 128×128；目标 = 同束 2e5 六张 128×128；**束级 train/val/test 切分**（test = 从未见过的新束）。
- **N 的语义**：宏粒子数（锚点 200,001 颗 ≈ 500 pC ≈ 3.1×10⁹ 真实电子，每颗代表 ~1.6 万）；N 是抽样预算非物理限制；物理下限由「必须分辨的最弱结构占比 f」决定（N·f ≳ 几十计数）；三重角色 = 输入端被除的噪声 / 目标端收敛密度 / 评价端可交易货币（N_eff）。
- 每格计数参考（实测）：2e5 被占格均值 34；1e4 子样本 ~1.7（非核区普遍 0–2 计数）。

### 真实初始分布锚点（2026-09-13 实测 + 单位定案 + 管理定案）

`~/pyaml-main/examples/SXFEL/elegant_files/injector.sdds`（SDDS1 小端二进制；列 x[m], xp[rad], y[m], yp[rad], t[s], p；Charge 参数；MD5 = `f39d905f96abd5588091dad6dd3884b2`）。

- **p = βγ**（elegant0 手册 §sdds_beam 第 91 页：「p = βγ is the dimensionless momentum」）。
- **束流画像（全部自洽）**：N = 200,001、Q = 500 pC、**pc ≈ 130 MeV**（SXFEL injector 出口量级）；σ_x = σ_y = 0.329 mm（圆束）；σ_xp = σ_yp = 29.1 µrad；corr(x,xp) = corr(y,yp) = 0.855（远离束腰）；横向零耦合；ε_n ≈ **1.26 mm·mrad**；σ_dp/p = 1.07e-3；σ_t = 2.41 ps；corr(t,p) = −0.371。**已非高斯**（xp/yp 峰度 ≈ +2.6、p 偏度 −1.4）。
- 分箱统计实测（20 万粒子全量，(x,xp) ±4σ）：128×128 占用格 35.8%、被占格均值 **34.0 计数**、峰值 485；64×64 占用 53.7%、峰值 1833。

### 一致性层级（主线的定义性约束）

1. **投影内重分箱一致**；2. **跨投影 4D 相容**（同物六影，抗幻觉脚手架；Phase 1 以软一致 PSD 罚项入场）；3. **可识别性缺口**（先验承担真实工作；"必须恢复什么"由预注册物理可观测量清单定义）。

### 根本质疑与应对（2026-09-13 用户提出——本线的核心科学问题）

**信息在**：六投影唯一确定二阶矩 Σ；投影面内现形的结构受约束；跨平面涨落耦合。**信息不在**：纯高阶 4D 关联（硬边界，任何方法不可恢复）；128 尺度格内分配（先验补全）。

**应对**：模拟中真值在手——细结构恢复率可测量而非承诺。验证阶梯：L0 重分箱一致 → L1 投影保真 → L2 超投影约束 4D 量 → L3 跨站传输。**机制统一性警告**：放大与幻觉同一机制——验证阶梯必须预注册。**信息预算可调**：多站点 = 相空间基旋转后的额外约束。**利害声明**：ML 增量价值压在细结构上——H8 是主战场；阴性则主张收缩并如实报告。

## 6D/4D 分布的投影表示（背景记录）

- **4D**：两两投影 **C(4,2)=6 张**；高斯下数学完备（10 个二阶量全覆盖，ε_4D 可算）；非高斯下不完备，隐藏耦合使投影发射度之积低估 4D 发射度；4D 直方图维度灾难 128⁴ ≈ 2.7e8 格。
- **6D**：**C(6,2)=15 张**；高斯下完备（21 个二阶量）；非高斯下有限投影皆不完备（Cramér–Wold）；128⁶ ≈ 4.4e12 格。
- 二阶量精度随 √N 改善；细结构可见性受分箱与统计双重限制。
