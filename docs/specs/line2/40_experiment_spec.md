## [S1] 实验矩阵

**Dependencies (optional):** `10`、`20`、`30` 全部完成

- **E0 基线（无训练，先行）**：裸误差–N 曲线、互差地板与参照噪声地板（`20` [S2]），两站 × N ∈ {1e3, 3e3, 1e4, 3e4, 1e5}。**E0 SHALL 先于 E1 的任何训练启动完成**（尺子先行，顺序由 run 日志时间戳可验证）。
- **E1 主对比（H3 + H1）**：@N_low = 1e4、站 0——独立版 vs 联合版 × 5 种子 = **10 runs**。
- **E2 放大曲线（H4 + H9）**：{3e3, 1e5} × 获胜变体（路由见 [S3]）× 5 种子 = **10 runs**，均在站 0；与 E1 的 1e4 结果合成三点放大主曲线（即方法可用域地图）。
- **E3 跨站泛化（H7 图像级）**：E1 获胜变体的 5 个 ckpt 直接应用于站 1 的 test 束输入（不重训练），见 [S2]。

### Claims

- C1: 实验矩阵 SHALL 覆盖 `20` [S2] 尺的全部 N 档（E0 五档 + E1/E2 消费 1e4/3e3/1e5）与两站。
- C2: 每 run SHALL 有独立 run 目录：`results/<run_id>/`（config.yaml、训练日志、ckpt、summary.json），且 manifest 含 `00` GC7 三元组。
- C3: E1 的 10 runs SHALL 仅在（变体, 种子）二维上不同——数据集、切分、max_steps=50000、物理档完全一致（GC4，由 config diff 自动断言）。
- C4: E2 的获胜变体 SHALL 由 E1 的 val 阶段结论按 [S3] 路由规则唯一决定（脚本读取，不人工指定）。
- C5: E0 的完成时间戳 SHALL 早于 E1 任一训练 run 的启动时间戳（尺子先行的可验证顺序约束）。

## [S2] 跨站泛化检验（H7 图像级）

**Dependencies (optional):** [S1] E3

- 同一 ckpt 分别应用于站 0 与站 1 的 **test 束**输入图组；各自计算 N_eff（`20` [S3]）。
- 预注册判据（阈值冻结于本 spec 批准）：比值 ρ = N_eff(站1) / N_eff(站0)——ρ ≥ 1 → 成立；0.5 ≤ ρ < 1 → 成立（弱，报告衰减系数）；ρ < 0.5 → 不成立；N_eff 触发上/下溢标记使 ρ 无法计算 → 不可判定。

### Claims

- C1: 检验 SHALL 仅使用 test 束（训练与调参全程未见的束）。
- C2: 三分类结论 SHALL 由 ρ 与预注册边界 {1.0, 0.5} 唯一决定（脚本化，无人工裁量）。
- C3: 站 1 的输入图组 SHALL 来自站 1 的 bin 边界与子采样（`10` [S4]）——不得用站 0 边界跨站套用。

## [S3] 出口门禁（三分类化）与变体路由

**Dependencies (optional):** [S1]、[S2]

- **两段式判据消费（审核 M2）**：**val 段**——变体路由（[S1] C4）与一切调参决策只消费 val N_eff；**test 段**——H1/H3/H8 出口门禁只消费 test 的一次性评估。两段 SHALL NOT 交叉。
- **获胜变体路由（审核 M3，全分支；消费 val 段成对计数）**：H3 路由计数 5/5 → 联合；4/5 → 联合（弱）；3/5 → 以 val N_eff 中位数较高者为获胜变体（报告标注"H3 不可判定"）；≤2/5 → 独立。出口门禁的 H3 计数另行消费 test 段成对计数（两段不交叉，见上两段式规则）。
- **（Phase 1.5 修订，99 v1.1）**：Phase 1.5 批次的获胜变体路由 = 两臂按站 0 @1e4 的 val_nll 排序取优（`50` [S5]），上条 N_eff 计数分支**整体取代**；Phase 1.5 的 test 评估调度归 `50` [S5]。本文件上述 N_eff 口径仅适用 Phase 1 批次的已执行 run。
- **H1（放大存在性）**：获胜变体 @1e4 的 5 种子 test N_eff 分布——成立：5/5 种子 N_eff > N_low 且中位数 ≥ 2×N_low；不成立：中位数 ≤ N_low；其余：不可判定。
- **H3（联合优于独立）**：同种子成对比较（5 对）——成立：5/5 对联合 N_eff ≥ 独立；方向成立（弱）：4/5；不成立：≤ 2/5；3/5：不可判定。
- **H8（细结构可恢复性）**：聚合维度 = test 束 × 站 0 × N_low = 1e4 × 5 种子中位数输出（`20` [S4] 预注册）；13 项观测量按 `20` [S4] 容差线（最近曲线档映射）的达标率——成立：达标率 ≥ 80%；不成立：≤ 50%；之间：不可判定；暗桶（B0/B1）的 M2 相对改进单独报告（不并入达标率）。
- 全部门禁阈值 {2×, 4/5, 80%, 50%, ρ∈{1.0, 0.5}} 冻结于本 spec 批准；输出 ∈ {成立, 方向成立(仅 H3), 不成立, 不可判定}。

### Claims

- C1: 每条门禁 SHALL 有唯一脚本实现，GIVEN 同一批 summary.json THEN 输出逐位一致（可复算）。
- C2: 门禁脚本 SHALL 仅消费落盘 summary 与数据集清单（不训练、不重推理、不读取训练期中间状态）；val 与 test 的消费边界 SHALL 由脚本内的数据路径断言强制。
- C3: 全部门禁输出 SHALL 为合法枚举值（含 H3 的"方向成立"），不得输出自由文本。
- C4: 变体路由 SHALL 覆盖 H3 的全部四种计数分支（含 3/5 的 val 裁定），无悬空分支（测试：构造四种 summary 验证路由）。

## Global Constraints

- 继承 `00` [S2] 全部（GC1–GC7）。
- 门禁与报告脚本 SHALL 只读（不训练、不推理、不修改数据集）。
- test 评估 SHALL 仅由本 spec 的矩阵调度执行一次（GC3；E3 的跨站应用属该唯一一次的组成）。
- 禁止断言研究方向：矩阵与门禁只定义"如何判"，不预设"判成什么"。
