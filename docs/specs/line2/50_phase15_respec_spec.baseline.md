## 已批准的变更清单（2026-10-12–13 讨论定案，用户逐项知情）

1. 选型准绳：val N_eff → val NLL/err + 训满预算（缺陷 #4 早停，T0-1）。
2. 变体路由改次级准绳（缺陷 #3 平局路由选劣臂，前置②）。
3. 定标口径改公共物理域，解禁 θ 踢角通道（缺陷 #1，前置①）。
4. κ 重参数化（无量纲化 + 跨档训练），与 #3 同批（缺陷 #2，T0-2）。
5. 迁移臂 stations=(0,)（E3 口径缺陷，exp5 + 前置①清账）。
6. 常数解（B-const）补入基线族（`40` D18）。
7. N_eff 降级为叙事尺度，次级准绳升主（前置②：两口径全饱和）。
8. "个体信息门禁"（增量对齐 cos + 打乱对照）正式化（前置③仪器与阈值）。
