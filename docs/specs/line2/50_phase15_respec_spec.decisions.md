## D1: 混合档训练替代 Phase 1 镜像矩阵（run 数 20 → 10）
**Phase:** write-spec
**Chosen:** 每个 run 的训练/验证集同时含三档 {3×10³, 1×10⁴, 1×10⁵}（每 step 均匀随机抽档，k_train = 5），2 臂 × 5 种子 = 10 runs；@1×10⁴ 的评估与 Phase 1 官方口径直接可比。
**Rationale:** 混合档使 κ 的 log₁₀N 维随 batch 变化（T0-2 判明的"档内常数"缺陷被结构性修复），且单一模型跨三档直接服务用户"训练一次、处处可用"的部署目标；与 Phase 1 的可比性已由 pre2 前后对照表（best_val/last 两列）承担，无需以矩阵镜像换取。
**Rejected:** 镜像 Phase 1 单档矩阵（E1+E2 = 20 runs）——保留结构但 log₁₀N 维在 run 内仍是常数，κ 修复不完整，且 run 数翻倍；单档 + 混合档各半对照——批内引入第二变量（档策略），门禁解读混杂（列为 deferred 候选，见 Out of Scope）。
**Supersedes/关联:** `40` D7 的路由准绳**计数分支整体**由本批 [S5]（val_nll 排序）取代（评估调度自 Phase 1.5 起归 `50` [S5]）。
**Spec section:** [S4] C2、[S5]
**Status:** live

## D2: κ 参考尺度 s_i 取公共域半宽
**Phase:** write-spec
**Chosen:** s_i = 坐标 i 的公共域半宽（(max−min)/2，由 v2 bin_edges 推得）。
**Rationale:** 无量纲化后 Σ 分量落在 O(1)（v1 为 10⁻¹¹~10⁻⁷ 被归一化层吸收）；s_i 从 edges 推得，训练/推理零额外配置，且定标口径变更时自动跟随。
**Rejected:** 锚点 twiss σ 作分母——引入单点标定依赖且对失配束的比值跨度过大；FODO 匹配包络 β——引入晶格依赖，与"位置无关估计器"目标相悖。
**Supersedes/关联:** 本条即 `30` D20 曾否决的"给 κ 补归一化并重训"之实施——`30` D13/D20 的"登记不改实现"处置由本批升级为预注册变更（99 v1.1 取代清单内声明）；`30` D17（独立臂第三分量取协方差）的口径**继续沿用**（[S4] cov_ij/(s_i·s_j)），登记关联以免再被读作未处理偏差。
**Spec section:** [S1]（s_i 定义）、[S4] C1
**Status:** live

## D3: 保留两臂（joint + independent）而非只训 independent
**Phase:** write-spec
**Chosen:** 2 臂 × 5 种子都训，路由按 val_nll。
**Rationale:** κ 修复后"共享主干 + PSD 软一致罚"是否有价值是尚未回答的预注册问题（v1 的 H3 平局与 err 反转都是在 κ 旁路条件下测的）；两臂同批成本低（共 10 runs），且路由规则（次级准绳）本身是需要验证的变更项。
**Rejected:** 只训 independent（err 口径优者）——会失去对"κ 修复后 joint 价值"的预注册回答；joint 臂作为唯一门禁臂——G3 读数会继承劣臂风险。
**Spec section:** [S4]、[S5]（routing）
**Status:** live

## D4: M6 容差线去偏方式 = 分半去偏 + 半正态一致性验证
**Phase:** write-spec
**Chosen:** 以一半 train 子样本估计 M6 偏差中位数并去除；容差线 = 去偏后 |·| 的 95 分位。可证伪验证（spec [S3] C3）：在另一半上 |中位|/σ < 1 且 95 分位/(1.96σ) ∈ [0.8, 1.2]。
**Rationale:** 前置④实测 M6 裸符号偏差 |中位|/σ = 24.7——v1 的 M6 容差线量的是子采样机械偏移而非噪声。分半设计使验证判据可证伪（一审 M3：单半区"减中位后 |中位|/σ<1"按构造恒真）；半正态一致性区间 [0.8,1.2] 把"是噪声线"变成有容忍带的实测断言。
**Rejected:** 直接放大 M6 容差倍数——掩盖口径缺陷且放大倍数无先验依据；从 13 项中剔除 M6——丢失观测量且改变 H8 语义；单半区自验证——判据按构造恒真（一审 M3）。
**Spec section:** [S3] C3
**Status:** live

## D5: G4 跨站门禁采用难度归一残差比 R_diff，原始比同步披露
**Phase:** write-spec
**Chosen:** G4 判定 = R_diff = (err_s1 − B_s1)/(err_s0 − B_s0) ≤ 1.10；原始比 err_s1/err_s0 并列落盘披露、不进判定。
**Rationale:** 前置①证实站 1 任务难度显著偏低（B-const 下限 0.035 vs 0.194）——只用原始比会把"任务容易"误读为"迁移无损"，这正是 pre1 要求在 99 登记的分母口径。
**Rejected:** 只用原始比 err_s1/err_s0（pre2 采用的披露口径）——站点难度不可比；用对数比——语义与 G1 的 advantage 口径不一致。
**Spec section:** [S1]（R_diff）、[S5] G4
**Status:** live

## D6: run 数修正声明（此前口头"20 run 级" → 本 spec 10 runs）
**Phase:** write-spec
**Chosen:** 10 runs（混合档使每臂仅训一次）。
**Rationale:** 用户在批准讨论中看到的"~20 个 run"是按 Phase 1 镜像结构的估计；混合档设计（D1）在满足全部七项变更目标的前提下把训练成本减半。本条目将该偏差显式化供用户在冻结审阅时确认。
**Rejected:** 维持 20 runs（10 混合 + 10 单档对照）——单档对照回答的是"混合 vs 专用"这一新问题，属 Phase 2 部署决策，不阻塞本批门禁，列为 deferred 候选。
**Spec section:** [S5]
**Status:** live

## D7: 混合档批内抽样 = 每 step 均匀随机（SeedSequence 派生）
**Phase:** write-spec
**Chosen:** 每 step 以均匀分布抽取当批档位，档位流由 SeedSequence(20260913) 派生、与数据子样本流独立 spawn。
**Rationale:** 档位混入梯度噪声可作为天然正则；独立 spawn 保证确定性重演且不与子样本选择流耦合。
**Rejected:** epoch 内按档轮换（档与 lr 调度/周期耦合，选型读数会被档周期污染）；按档复制加权（引入无先验权重超参）。
**Spec section:** [S4]（混合档条款）
**Status:** live

## D8: v2 只改边、不改粒子（同种子重生成对账）
**Phase:** write-spec
**Chosen:** v2 用同一 SeedSequence(20260913) 链重生成粒子（与 v1 逐位一致），仅 bin_edges 取公共域。
**Rationale:** 保持与 v1 全部产物的可比性（同一 A⊂B、同划分、同 FODO）；θ 可见性缺陷被定域在"边"这一层（前置①），修复应最小作用域。
**Rejected:** 重新抽种子生成新粒子集——破坏 v1↔v2 对账能力且无必要；在读取时动态重分箱（保留 v1 文件）——落盘产物 schema/边界不一致，门禁与容差线的可复现性受损。
**Spec section:** [S2] C1
**Status:** live

## D9: 选型/路由准绳替换的集中声明与"val err 半边"的落实
**Phase:** write-spec
**Chosen:** 选型与路由唯一准绳 = val_nll（三档等权中位聚合，[S3] C2/[S4] C4/[S5] 路由）；基线批准项中的"err 半边"落实为**门禁侧 test 端 M1**（G1/G4/G5 的判定读数），不作为选型输入——选型单准绳化以避免双准绳平局仲裁。
**Rationale:** v1 的教训是"准绳饱和 + 双读数并存导致选型语义空洞"；单一非饱和准绳 + test 侧门禁分离是最小可审计结构。
**Rejected:** val_nll 与 val err 双准绳（需定义二级仲裁，复杂化且无证据收益）；保留 N_eff 为并列披露兼判据（T0/pre2 已证其两口径全饱和）。
**Supersedes:** `30` D6（选型 = val N_eff 的准绳选择）、`40` D7 的 N_eff 路由基、`00` GC3 的"唯一主指标"表述与 `30` [S3] C2 的 best_val 语义（全部在 99 v1.1 取代清单内逐条登记）。**关联：** `30` [S1] 的 log₁₀N_low 文字口径与实现语义（6·N_low）之差由 `30` D14 已登记；v2 沿用 6·N_low 实现语义，该文字随 30 [S1] 改写时对齐。
**Spec section:** [S3] C1/C2、[S4] C4、[S5] 路由
**Status:** live

## D10: val_nll 聚合粒度与 val 子样本口径
**Phase:** write-spec
**Chosen:** 逐 (束, 子样本) NLL → 每档全束中位数 → 三档等权算术平均；val 评估子样本 = subs 0–4（k=5）。
**Rationale:** 中位数对个别异常束稳健（与 Phase 1 的 M1 聚合哲学一致）；三档等权使选型不偏向任何部署档；k=5 在选型开销与稳定性间取衡（v1 val 全量 subs 口径在混合档下成本 ×3）。
**Rejected:** 全束均值（对重尾 NLL 敏感）；subs 0–19 全量（选型开销 ×4，patience 判定分辨率无增益）；只按 1×10⁴ 档选型（混合档下丢失跨档信息，违背 D1 动机）。
**Supersedes/关联:** `30` D19 的 val 子集口径在本批按上式重定义（99 取代清单内声明）。
**Spec section:** [S3] C2
**Status:** live

## D11: G1/G5 阈值 0.90 与 G4 阈值 1.10 的依据
**Phase:** write-spec
**Chosen:** G1/G5 的 win_rate ≥ 0.90；G4 的 R_diff ≤ 1.10（方向带至 1.25）。
**Rationale:** 预注册线而非实测承诺。G1/G5：pre2 在 last 口径实测赢率 150/150、中位 advantage +0.0993——0.90 在"复现该量级"与"容许种子波动"间取衡（v1 的 40–69/150 反例证明低于 0.9 的赢率可与"聚合占优"共存，故不能取更低）；G4：pre2 站间原始比 −7.4%（站 1 更优）是在"训练含站 1"的旧口径下测得，真迁移首测无先验，1.10/1.25 为工程可接受的退化带（类推 40 [S3] 的 80%/50% 双线结构）。
**Rejected:** 以 pre2/pre3 实测值本身作阈值（150/150、R_diff=1.0）——零容忍线无统计裕度，把"复现波动"误判为失败；阈值 ≥0.95 / ≤1.05——同类问题。
**Spec section:** [S5] G1/G4/G5
**Status:** live

## D12: [S2] C3 θ 可见性阈值的依据与量级
**Phase:** write-spec
**Chosen:** 阈值 M1 ≥ 1×10⁻³，定位为"保守判可见下限"；依据 = v1 逐束自定标下 θ 单旋钮 M1 = 0.0000（缺陷本体）与 pre1 公共域口径实测 0.74–0.81（裕度 > 2 个数量级）。
**Rationale:** 一审 M6 指出"分箱地板 ~6×10⁻⁴"溯源不实——该数是 v1 语境的 Σ 分量量化地板（`30` D15），非 M1 地板，不可引为依据；改用 pre1 的同口径实测值后，阈值的作用只是"防退化回归钉"（v2 不得回到不可见），而非精度声明。
**Rejected:** 沿用 6×10⁻⁴ 并标注来源为分箱地板——溯源不实（一审 M6）；把阈值提高到实测同量级（0.5）——会把回归钉变成对分箱细节的过强约束。
**Spec section:** [S2] C3
**Status:** live

## D13: 域外粒子处理选夹取（计数守恒），0.1% 为预注册会计阈值
**Phase:** write-spec
**Chosen:** v2 公共域外的粒子**夹取至最近边界格**（∑counts = N 守恒，`00` GC5 无需取代），逐束记录夹取计数；全数据集夹取占比 ≤ 0.1%（分母 = 全数据集粒子总数）为构建失败线。
**Rationale:** 一审 R2 指出"丢弃"读法会违反 `00` GC5 计数守恒且未登记取代——夹取使计数守恒自动成立、把改动限制在边层；0.1% 依据 = train 池化 + 5% 外扩的域裕度远大于实测束间窗口差（pre1：x/y <0.05%、xp/yp ±1–2.6%），正常情况下夹取量应接近零，该线只作为"定标规则写错"的保险丝而非预期发生的路径。
**Rejected:** 丢弃域外粒子（违反 `00` GC5，需额外登记取代且引入 ∑counts = N − trunc 的新约定）；放宽为零阈值的纯记录——失去"保险丝"作用，定标错误将静默通过；提高外扩至 10% 以求零夹取——域变宽稀释分辨率且无先验依据。
**Spec section:** [S2] C6、[S2] C1
**Status:** live

## D14: 范围边界显式化——单一固定 FODO 两站；任意元件组合与非线性/加速排除（用户确认）
**Phase:** write-spec
**Chosen:** 在 [S1] 增加"Phase 1.5 晶格边界"定义（恰一条冻结 FODO、元件集 = 四极 + 漂移、束差异仅来自入射抖动、**抖动 ≠ 换晶格**）；G4 标注限于该晶格两站、不含跨晶格声明；Out of Scope 的晶格随机化条款逐字列出被排除的元件类型（二极磁铁、六极磁铁等非线性元件、加速能量变化）。
**Rationale:** 用户 2026-10-13 审阅时将 Phase 1.5 表述为"测试束流覆盖任意数量及组合的四极/二极/漂移段下的重建能力"——该读法实为 Phase 2 晶格随机化。用户经澄清确认按阶梯式范围执行后，要求把边界写死；冻结 spec 不可改，边界歧义必须在冻结前消除（防目标原话"任何加速器元件"被读成本批承诺——读法 B）。
**Rejected:** 维持隐式边界（靠 Out of Scope"晶格随机化"条款的语义覆盖）——用户审计表明误读确实发生，字面消歧成本一轮快审、收益是合同零歧义；把任意元件组合纳入 Phase 1.5——废弃重写级变更，破坏与 Phase 1 的可比性且混淆"修测量"与"扩域"两个变量（用户已否决）。
**Spec section:** [S1]（晶格边界）、[S5] G4、Out of Scope
**Status:** live

## D15: G1–G5 失败归因路径预注册 + 门禁枚举结论的合法性原则
**Phase:** write-spec
**Chosen:** ① 预注册五条门禁各自"不成立"时的第一嫌疑与归因仪器——**G1** 反超失败 → 任务形式问题（绝对图组 vs 残差式），工具 = B-const 对照 + 逐束 advantage（pre2 口径）；**G2** 个体信息缺失 → 模板化，工具 = 对齐+打乱探针 + κ 置乱消融（T0-2/exp2 仪器）；**G3** 观测量缺口 → 已知集中 5 项（σ_yy/σ_xx/m5_halo/σ_xpxp/σ_ypyp），工具 = pre4 偏差/方差分解（区分可校准偏移 vs 真缺陷）；**G4** 跨站退化 → 站间难度或真退化，工具 = R_diff 分母口径 + pre1 理论传播（RΣRᵀ）；**G5** 跨档失败 → 混合档损害专用性能，工具 = 触发 Out of Scope 既有条目"混合 vs 单档对照"转正。② 声明两层验收分离：**G1–G5 的四值枚举结论（含"不成立/不可判定"）均为合法交付**，门禁不成立触发的是归因与新预注册流程，不构成实现缺陷或工程验收失败（先例：Phase 1 的 H7/H8）。③ 全量 pytest 绿为仓库级交付惯例（各 Claim 具名测试之外的机械终检），维持惯例、不入 spec 正文。
**Rationale:** 预注册精神要求"失败后先查什么"与判据本身同样在看结果之前写死——事后归因存在机会主义风险；三轮诊断（T0/pre 批次）建成的归因仪器是本批的可复用资产，逐门禁绑定工具可把"结果不理想 → 定位原因"的周期从周级压到小时级。
**Rejected:** 把归因表写入 spec 正文——归因路径是分析指引而非可判定契约，且任何正文改动触发全文重审；不预注册归因（失败后再议）——与"先写判据后看结果"的本批首要原则相悖。
**Spec section:** [S5] G1–G5（判定）、[S3] C5（仪器）；关联 `40` D21/D22
**Status:** live
