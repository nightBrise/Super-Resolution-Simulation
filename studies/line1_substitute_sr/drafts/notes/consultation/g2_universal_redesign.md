# G2 通用型主指标重设计：从"修补"到"重新思考测量"

> **作者**：主 agent
> **触发**：Qwen 深度审查发现的 G2 颠覆性问题——主指标 ε_high^mask 的掩膜主要选中 β 折叠边缘而非 c_high 精细结构（脚本 a n=100 实证 ch_in_mask=0.466、b_in_mask=1.092），导致 M4 主判定可能不测 c_high 增益而测"c_mid 折叠已知信息复用"。
> **用户要求**："通用型方案，重新思考主指标测量问题"——不只是修补现状掩膜定义，是从测量哲学层面重设计。
> **范围**：替代 Qwen 提案 2 的分支甲（差分能量掩膜）和分支乙（保留+披露）两个"现状补丁"方案，给出一个对所有类似项目都适用的主指标测量原则与具体实现。

---

## §1 测量哲学：主指标必须"语义对齐"而非"能量对齐"

**原设计的问题（哲学层面）**：

主指标 ε_high^mask 的设计逻辑是"用 H 高频能量最集中的像素区域作为'c_high 精细结构区域'"——这隐含了**能量对齐假设**："H 高频能量 ≈ c_high 精细结构能量"。但**这只是粗略近似**——H 高频能量来源有：(i) c_high 精细结构（a₃/γ/b₁ 驱动的精细折叠）、(ii) c_mid 折叠边缘（β 驱动的折叠在锐利处有高频）、(iii) c_low 物理量产生的高频底噪（如头部光斑）、(iv) 渲染伪影。

**Qwen 揭示**：实测能量主要来自 (ii)，而研究声称测的是 (i)——**测量工具和测量目标错配**。

**通用原则**：

> **主指标的构造必须直接对应"研究声称测什么"，而非"哪个像素能量最高"**。换言之：**主指标 = f(研究问题的形式化) ≠ f(最容易计算的代理量)**。

这要求每个主指标都有**形式化的"测什么"陈述**和**构造的"为什么是它"证明**。

---

## §2 四种主指标重设计方法（从最通用到最具体）

### 方法 A：物理量级直接评估（最根本、最通用）

**思路**：绕开"像素高频能量"中介，直接评估 c_high 物理量。c_high 三个参数（a₃/γ/b₁）控制的具体物理量：
- **a₃（三阶 S 形）** → 折叠 S 形曲率（三阶多项式系数）
- **γ（三阶卷曲）** → 主折叠边缘的微卷曲度
- **b₁（局部厚度变化）** → 局部能散 σ_δ(z) 的 z 依赖斜率

**主指标** = 在 H 上直接计算这些 c_high 物理量，再与真值标签（m）中的对应值比较：
- `c_high_metric_1 = |a3_pred − a3_true| / |a3_true| + 1`（类似 a₃/γ/b₁ 三个）
- `c_high_metric_2 = σ_δ(z) 形状匹配的 L1 距离`（b₁ 直接对应）
- `c_high_metric_3 = 折叠主轴曲率匹配度`（a₃ 间接对应）

**优点**：直接测"c_high 在 H 里的痕迹"——物理量是 c_high 的因，是网络输出的果，**因果对齐**。
**缺点**：(1) 需要重新定义"c_high 物理量"的提取算法（每个量都要写清楚怎么从 H 图像提取）；(2) 替代"像素 L1/L2"的简单指标——可能失去对总误差的代表性；(3) M1/M2 已落盘的数据产物不含这些物理量——需要重渲染。
**通用性**：★ ★ ★ ★ ★（最根本。任何"用什么掩膜"的问题都应先问"能否直接测物理量"。）
**实施成本**：高（需重定义主指标、重渲染数据、重训练模型、新测试）。**不推荐用于 M4（来不及）。作为 M5/M6 升级方向。**

### 方法 B：差分能量空间掩膜（最实用、最推荐）

**思路**：掩膜选择"**对 c_high 敏感**的像素"，而非"**H 高频能量高**的像素"。具体方法：

**算法**：
1. 渲染 H（完整参数）和 H_noch（a₃=γ=b₁=0，其余相同）
2. 取 `Δ = H − H_noch`（c_high 引起的差异图）
3. 掩膜 `M_c_high = (|Δ_hp| 的 90% 能量像素集)`——只依赖 c_high 引起的变化

**数学性质**：
- **语义对齐**：掩膜定义的"c_high 区域" = "c_high 引起变化的区域"——直接对应研究目标
- **数据生成口径无关**：不依赖 σ_smooth,H（因为 Δ 不受 σ_smooth,H 整体平滑影响——σ_smooth 是加性卷积，Δ 是两次卷积相减，互相抵消）
- **先验无关**：不依赖 P2/B 方案——是 H 本身性质，与先验无关
- **可复现**：每次新数据只需重渲染 H 和 H_noch（生成器已支持 c_high 清零版本）

**主指标修订**：`ε_high^mask = mean(|Ĥ_hp − H_hp| ⊙ M_c_high)` 其中 M_c_high 由上定义

**额外披露要求**：为了透明化，必须同时报告：
- `ch_in_mask` = Σ(|Δ_hp| ⊙ M_c_high) / Σ(|Δ_hp|)——掩膜内 c_high 差分能量占比（应 ≥90% by construction）
- `b_in_mask` = Σ(|Δβ_hp| ⊙ M_c_high) / Σ(|Δ_hp|)——β 引起的差分在掩膜内的能量占比（应 ≪ch_in_mask）
- `other_in_mask` = 1 − ch_in_mask − b_in_mask——其他来源（应接近 0）

**优点**：
- 直接对齐研究目标（"测 c_high 精细结构恢复"）
- 与 σ_smooth,H 口径无关（任何 σ_smooth 都给出同一掩膜）
- 可在 M4 立即实施（生成器已支持 c_high=0 渲染）
- 通用（任何用"高频能量作 c_high 代理"的研究都可改用此法）
**缺点**：(1) 计算成本 2× 渲染（要同时渲染 H 和 H_noch）；(2) 需要修改 f_beam 支持 c_high 清零（容易）；(3) 成分分解增加了报告复杂度。
**通用性**：★ ★ ★ ★（对"基于高频能量"的所有判据都适用——这是 Qwen 揭示的根因的真正解药）。
**实施成本**：中等（1-2 天：渲染参数 + 评估函数 + 测试 + 报告模板）。
**推荐**：**作为 M4 主指标的修订方案**。

### 方法 C：双频带分离评估

**思路**：不再用单一 f>1/8 频带，改用**两个频带**——
- **f1 = f(0, 1/16]**：低频，β 折叠的"主结构"贡献（c_mid 主导）
- **f2 = f(1/16, 1/8]**：中高频，c_high 精细结构贡献

**主指标**：分别报告 ε_low 和 ε_high，**只把 ε_high 用于 c_high 增益判定**。

**优点**：(1) 不改变掩膜——纯频带分离；(2) c_high 在 f2 的能量占比比 f>1/8 全带更高（剔除 f>1/8 顶部 fN 附近的伪影）。
**缺点**：(1) f2 仍受 σ_smooth,H 整体平滑影响；(2) 只是"减弱"问题，不是"解决"。
**通用性**：★ ★ ★（对频带判据的简易补丁，但根因未除）。
**实施成本**：低（1-2h）。
**推荐**：**不推荐作为 M4 主指标**——是 G2 的治标，但与方法 B 治本不冲突。可与方法 B 并用（同时报告 f1/f2 频带指标 + 差分掩膜指标）。

### 方法 D：先验不变量校验

**思路**：在主指标之外加"先验独立性"校验——确保先验**没有携带**主指标所测对象的信息。方法：

**算法**：
1. 定义"先验信息泄漏指数" `Π_leak = mean(|P2_hp − H_noch_hp| ⊙ M_c_high) / mean(|Ĥ_A_hp − H_hp| ⊙ M_c_high)`
2. 若 `Π_leak > 阈值（如 0.5）` → 先验在主指标区域携带显著信息，**主指标不再测"独立先验增益"**
3. 在 final_report 中**强制报告** `Π_leak`，超过阈值时附警告

**优点**：(1) 不改变主指标——只加披露；(2) 直接对应"研究声称的'先验增益'"的科学性。
**缺点**：(1) 不解决 G2 本身——只让 G2 透明化。
**通用性**：★ ★ ★ ★（对任何"先验不暴露 c_high"的研究都适用——50 [S11] C4 的**能量级**验证）。
**实施成本**：低（评估函数 + 报告字段）。
**推荐**：**作为方法 B 的辅助披露**——既用差分掩膜（治本），又报告先验泄漏指数（透明化）。

## §3 推荐方案：方法 B + D 组合（差分能量掩膜 + 先验泄漏披露）

### 3.1 主指标重设计（核心）

**修订** `70_evaluation_spec.md` [S7.1] C1/C2：

**修订前**：「$M_{c_{\text{high}}}$ 为 |H_hp| 像素按幅值降序、累计能量达 \|H_hp\|₁ 的 90% 的最小像素集」

**修订后**：
- 「$M_{c_{\text{high}}}$ 为 **c_high 差分能量空间掩膜**：渲染完整 H 与 c_high 清零版 $H_{\neg ch}$（a₃=γ=b₁=0，其余参数相同），取 $\Delta = H - H_{\neg ch}$，以 $|(\Delta)_{hp}|$ 像素按幅值降序、累计能量达 $\|\Delta_{hp}\|_1$ 的 90% 的最小像素集。掩膜只依赖真值参数、与退化无关、与 σ_smooth,H 整体平滑无关、三方案共用。」
- 「**成分分解强制披露**：主指标报告 SHALL 同步给出三方案在 $M_{c_{\text{high}}}$ 内的能量来源分解（c_high 差分 / β 差分 / 其余，方法见 `scripts_tmp/g2_c_high_leak.py` 归档版）；三方案任一分解中 `b_in_mask > ch_in_mask × 1.5` 时 MUST 附先验能量级泄漏分析。」
- 「**先验泄漏指数 Π_leak 强制报告**：在 $M_{c_{\text{high}}}$ 内，先验 P2 携带的 c_high 差分能量占比 = mean(|P2 − $H_{\neg ch}$|_hp ⊙ $M_{c_{\text{high}}}$) / mean(|H − $H_{\neg ch}$|_hp ⊙ $M_{c_{\text{high}}}$)；Π_leak > 0.5 视为先验在主指标区域结构性占优，final_report MUST 显式标注」

**注**：同时保留原 |H_hp| 掩膜作为**对照掩膜**（报告"对照掩膜下的指标"列）——既不丢历史信息，也展示新掩膜的差异。

### 3.3 与 Qwen 提案 2 的关系

- **Qwen 提案 2 分支甲**（c_high 差分能量掩膜）：与方法 B 等价。我提出的方案 B 是 Qwen 分支甲的形式化与扩展（增加成分分解 + Π_leak 强制披露）
- **Qwen 提案 2 分支乙**（保留定义+披露）：我提出方法 D（Π_leak 强制）作为分支乙的更严格执行——比 Qwen 更主动
- **综合**：方法 B（治本）+ 方法 D（透明）= Qwen 两分支的"严格合并版"

### 3.4 通用性论证

- **不同 σ_smooth,H 都成立**：方法 B 的掩膜只依赖 Δ = H − $H_{\neg ch}$，σ_smooth 是加性卷积，Δ 中的 σ_smooth 卷积被减法抵消——掩膜与 σ_smooth 无关
- **不同网络结构都成立**：掩膜只依赖真值参数，与网络结构无关（评估后处理）
- **不同退化都成立**：掩膜在退化前计算（对 H 而非 L），与退化参数无关
- **不同 c_high 实现都成立**：a₃/γ/b₁ 的具体物理含义可以替换（如换成更复杂的 c_high 模型），掩膜构造方法不变

**这才是"通用型"**——不是修补 G2 本身，是**设计原则**：
- **原则 1**：主指标必须因果对齐（直接测研究声称的目标）
- **原则 2**：掩膜选择应基于"敏感度"而非"能量"（参数差分 = 物理量因果链）
- **原则 3**：成分分解是必要的（主指标是单标量，但物理来源是复合的——必须披露）
- **原则 4**：先验独立性是可量化校验（Π_leak）——不是"先验不暴露 c_high"的字面校验

## §5 风险与限制

| 风险 | 缓解 |
|---|---|
| 方法 B 计算成本 2×（H + $H_{\neg ch}$）| 数据生成阶段预渲染（一次性成本），评估阶段只读 → 训练无影响 |
| Δ 在 c_high=0 边界处的数值稳定性（Δ 极小处 Δ/Δ_hp 噪声）| 掩膜构造用 \|Δ_hp\| 排序，天然处理极小值（极小值排在后面，不入选 90% 能量）|
| "差分能量"在 σ_smooth=0 时退化为 |H| 能量（方法 B → 原方法）| 这是连续过渡——σ_smooth→0 时方法 B 趋近原方法，无跳变 |
| 成分分解的 b_in_mask 仍可能高（β 折叠 + c_high 共同贡献高频）| 这是诚实披露的一部分——如实报告 + 解读 + 不让"高 β"等于"方法失效" |
| 主指标修订 → 旧 EXP-01a 评估结果失效 | 全部重评（评估函数纯后处理，几小时）|
| 50 [S11] C4"先验不暴露 c_high"字面 vs 能量级 | Π_leak 量化校验，**字面不变，含义加强**（从参数级到能量级）|
