## 7. 设计理由（Why）— 必含章节

### 7.1 为什么用合成函数替代直接模拟（M1 总设计）

本项目的研究方式是**替代验证（Substitute Verification）**：不直接用 elegant/Ocelot 做高保真仿真，而是用可控的解析生成函数 f(x)→(H,L,P) 构造严格配对的训练数据。理由：
- **选择方案**：解析参数化生成（20 [S4] Level 1 五项要素：非高斯剖面、不对称、局部厚度变化、三阶中心线、压缩折叠映射）
- **备选方案**：直接调用 elegant/Ocelot 生成相空间 → 需要完整束流物理建模与大量标定，第一版无法聚焦"先验能否帮助超分"这一核心问题；真实数据 → 无标签真值 H，且无法受控构造精细结构
- **取舍依据**：先验增益的归因需要"精细结构在 L 中不可分辨、在 H 中可稳定分辨、由参数决定"这一可受控的三态结构；解析函数可精确保证；若解析函数上验证成功，再迁移到 elegant/Ocelot（00 [S1] 逻辑链）
- 折叠映射 z_f = z + αδ + βδ² + γδ³ 的 Jacobian 恒为 1（保面积），密度变换无需修正，反向采样（map_coordinates order=1）即物理正确的光滑渲染；配合高斯平滑 σ_smooth,H 避免网格伪影（20 [S3] C4/D8）

### 7.2 为什么参数范围这样定

- **选择方案**：以上海软 X 射线 FEL（SXFEL）公开设计参数推算归一化锚点（20 [S9]「参数数值范围」小节），逐参数范围 + 压缩三态联合约束 + 掩膜 W1–W8
- **备选方案**：完全独立均匀采样 → 物理上荒谬组合（如 C 与 a₁ 无关联）；无约束范围 → 折叠溢出窗口或数值不稳定
- **取舍依据**：压缩因子 C=1+a₁α 是物理控制量（压缩器 R₅₆ 语义），联合采样保证欠/最佳/过压缩三态可控覆盖；W1–W8 保证 σ_eff>0、σ_δ>0、窗口覆盖、折叠在窗内、精细结构窗口 2.5px<w_fine≤0.8σ_K；掩膜拒绝统计记入数据版本元数据（可复现）
- 三态配额收集（非纯拒绝采样）：W3/W6 对 α、C 的选择性拒绝会使纯拒绝采样下三态占比漂移（实测 ~7pp，超 05 ±5pp 容差），配额保证严格 1/3

### 7.3 为什么退化协议这样设计

- **选择方案**：固定顺序 Blur（各向同性高斯 σ_K）→ Downsample（r=4 块求和，保总强度）→ Noise（加性高斯 σ_n，零值截断），输出 L 与 L_clean
- **备选方案**：直接抽稀/缩放 H（C2 禁止）→ 混叠使 L 意外保留高频；先下采样后模糊 → 抗混叠失效；只输出含噪 L → 无法分离模糊与噪声贡献
- **取舍依据**：先模糊再下采样防混叠（30 [S2]）；块求和满足"保总强度 ΣL=Σ(K*H)"（公式优先于"块平均"措辞，OQ-30-01）；r=4 使 256→64，精细结构 w_fine/r<1 在 L 中基本不可分辨（30 [S6] 经验规则）；σ_K=2×w_fine 中位数、σ_n=尾部 SNR 2–5 是预注册标定口径（30 [S12]），M1 采用初始值（尾部 SNR 2 档，D8 门需此档）
- SNR_hf<0.1 定量判据（30 [S6] C8）用高通带 f>1/8 的功率比，M1 实测中位数 0.077，验证"D8 精细结构不可清楚分辨"

### 7.4 为什么先验这样设计

- **选择方案**：P2（中阶图像先验）保留 c_low+c_mid（a₂、β），显式清零 c_high={a₃,γ,b₁}，更强平滑 σ_smooth,P>σ_smooth,H；σ_smooth,P 初始候选中心 2×σ_smooth,H，扫描 5 档
- **备选方案**：P1（仅 c_low）→ 丢失主折叠，先验价值不明显（40 D2）；P3（含 c_high）→ 泄露精细结构答案，仅限上限分析
- **取舍依据**：同源（40 [S2]）保证先验与 H 物理相关但不等；c_high 显式清零实现"扰动不变性"（★ 全项目最重要测试：改 a₃/γ/b₁ → P₂ 逐位不变）；M1 实测 2× 中心档 L1 比值 0.17<0.2 判"过度逼近"，取候选集上档 2.6× 得 0.284 ∈ (0.2,0.9)，说明 σ_smooth,P 需明显大于 H 平滑才能保持"可学的高频残差"；最终值待 EXP-01d 标定

### 7.5 为什么损失与上采样这样设计

- **选择方案**：空域-频域混合损失（L_space 逐像素 L1 + L_spec 五倍频程等权谱 L1，λ=1.0 冻结）；L_up 用 bilinear 4× 上采样 + 总强度归一化
- **备选方案**：纯 L1 → 条件中值解平滑掉精细结构、频谱偏差优先拟合低频（wang2026 依据）；L2 → 对尖峰敏感；可学习上采样 → 残差任务不清、公平性复杂（50 [S8] C3）
- **取舍依据**：频域项显式约束各频段（等权分带防低频主导）；FFT ÷N² 使两损失同量级（λ=1.0 等权成立）；f>f_N 角点剔除（无物理意义）；L_up bilinear 保总强度、无负值过冲，与插值后归一化自然衔接；三方案统一（公平性）

### 7.6 为什么测试策略这样设计（M1 执行视角）

- **选择方案**：05 三层铁律——只断言协议/契约/不变量（禁止断言研究结果）；每类泄露有 ★ 扰动不变性测试；L0/L1 纯 CPU ≤8min
- **取舍依据**：M1 阶段把 20/30/40 的全部 AC 机械化为可重复测试（unit 快反馈 + acceptance 慢验收 + 网格收敛 slow）；防泄露优先（c_high 不变性、无自选随机源）；测试全绿是 M1 退出的组成部分（00 [S7] C1）
- B 类歧义（OQ-40-02/03/30-01）不阻塞推进：按 05 [S7] 7.1 类别 B 咨询记录 + 99 登记 + xfail 标记，冻结期不改 spec
