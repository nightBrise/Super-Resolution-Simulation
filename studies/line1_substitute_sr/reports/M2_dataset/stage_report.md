## 4. 失败模式（如有）

### 失败 1：G0(b) 探针字面 ρ 定义不可操作（B 类，OQ-80-01）
- 触发条件：按 80 [S9] 字面定义实现探针评估 → s_x_literal=1.0 恒失败
- 诊断：字面 ρ = ‖(L_up)_hp‖₁/‖H_hp‖₁ 恒 ≈ 2.75（归一化口径），对 c_high 参数 x 波动 <0.3%——被 64→256 双线性插值块边缘伪影（f≈1/4 落入 f>1/8 通带）与高斯核截断泄漏主导，ρ 度量谱形差而非精细结构存活；主 agent 独立复算确认（未归一化口径 ρ≈44 = 2.75×16，源于块求和保强度使 L_up 总强度为 16）
- 选择的失败路径：05 [S7] 类别 B → 第二级咨询（Qwen 3.8 Max，agent-58）
- 处置过程：Qwen 裁定接受**差分形式** ρ(x) = (‖L_up(x)_hp‖₁ − ‖L_up(x₀)_hp‖₁)/‖H(x)_hp‖₁（x₀ = c_high 清零，L_up 总强度归一化），实测 ρ_diff ∈ [−0.032, 0.035] 全 <0.1 → s_x=0.0 通过，阈值语义保留；修订 80 [S9] G0(b) 文本的建议已提交用户（EXP-01a 前批准）；字面量继续计算归档为诊断

### 失败 2：初始标定值与 30 [S6] C8 判据互斥（B 类，OQ-30-02）
- 触发条件：σ_K=2×median(w_fine)≈10.37 下，C4 尾部口径 σ_n≈1.2e-5 → SNR_hf≈1.7 超标；C4 全图均值口径 σ_n=1.22e-4 → SNR_hf=0.167 仍超标
- 诊断：两判据对 σ_n 拉力相反（C4 锚尾部小值，C8 需大值），σ_K=2×median 处联合不可满足；加大 σ_K 是缓解方向（10.37→11.0 使 0.167→0.072）
- 处置：M2 采用 σ_K=11.0 + σ_n=1.22e-4（SNR_hf=0.072 通过），登记 manifest；Qwen 裁定 σ_K 取整可接受（登记即可），σ_n 口径修订 30 [S12] C4（增补"与 C8 不相容时"分支），EXP-01 联合标定协议预注册；已提交用户

### 失败 3：40 [S5] C5 hp 能量预算比主判据不可操作（B 类，OQ-40-03 升级）

## 7. 设计理由（Why）— 必含章节

### 7.1 为什么数据集按参数空间划分且 γ 挖块洞
- **选择方案**：60 [S8] 协议——先按 c 划分（同 c 噪声实现不跨划分）；test_id 与 test_pb 1:1；test_pb 块维度 |γ|∈[0.3,0.4]（固定总体分位秩 [0.4,0.6]，中央 20% 分位带）；train/val/test_id 块外条件采样、test_pb 块内条件采样
- **备选方案**：随机图像划分 → c 泄露（同一物理样本的噪声变体跨划分）破坏独立检验；test_pb 用经验分位数 → 划分随数据集漂移不可复现
- **取舍依据**：γ 是 c_high 精细参数（三阶卷曲），其幅度中央分位带对超分网络是"插值区"——检验网络在未见过的 γ 中间带的表现（40 [S4]：部分可见/可推断 vs 高分辨率才清楚的分层）；固定总体分位数（非经验）保证划分可复现；块外采样保证训练集不含块内样本（测试独立性）

### 7.2 为什么 HDF5 字段与 manifest 这样设计
- **选择方案**：60 [S14] 契约——每划分一文件，图像字段 H/L/L_clean/L_up/P2（float32 + gzip4 + 按 sample 切分），元数据 sample_id/c 全字段/m 全集/seed_i/掩膜标记/m_L；manifest 含三元组、划分指派、γ 块信息、标定值、掩膜统计
- **取舍依据**：L_clean 存盘（批次二十 Q4：供 SNR_hf 批量检查与 G0(b) 探针）；L_up 存盘（训练输入，避免每次加载时重复上采样，保证三方案消费同一版本输入）；seed_i 落盘使噪声可复现；manifest 三元组（code/data/spec version）是 N8 预注册对账的数据来源（60 [S14] C1）

### 7.3 为什么 G0 探针采用差分形式（B 类操作化）
- **选择方案**：差分高频存活比（分子 = c_high 驱动的 L_up 额外高频，减 c_high 清零基线；分母沿用 ‖H_hp‖₁）
- **备选方案**：字面 ρ（实测恒 ≈2.75 对 c_high 不敏感，门禁恒失败）；差图像范数（更保守但当前实现已通过且余量充足，降为诊断字段）
- **取舍依据**：字面量被插值伪影主导（根因：64→256 双线性插值块边缘 + 高斯核截断泄漏），差分减去与 x 无关的底噪，恢复"c_high 精细结构是否存活"的规格意图；阈值 0.1 语义保留（存活高频 ≥ H 高频 10%）；L_up 总强度归一化与 50 [S13] 网络输入口径一致

### 7.4 为什么初始标定值这样取
- **选择方案**：σ_K=11.0（2×median(w_fine)=10.37 上取整）、σ_n=1.22e-4（尾部信噪比 2 档全图均值口径）、σ_smooth,P=2.6×σ_smooth,H（40 [S5] 候选集上档）
- **取舍依据**：σ_K 取整在初始值容差内（EXP-01 正式标定后重生成）；σ_n 全图均值口径是 C4 尾部口径与 C8 联合不可满足下的可操作选择（Qwen 裁定：σ_n 以 C8 为硬约束 + 主束 SNR≥2 下限，尾部降诊断）；σ_smooth,P 上档使 AC14 L1 比值 0.284 落带（2× 中心档 0.17 < 0.2 判泄露）

### 7.5 为什么探针集不入训练集、test_ood 用 D2 初始值
- **选择方案**：探针集（3×200）独立归档于 probe_sets.h5；test_ood 子集 A（EXP-06 极端参数）用 D2 初始值生成、EXP-01 标定后重生成（批次二十一 Z5）
- **取舍依据**：探针是门禁评估工具，进训练集会造成数据泄漏与 G0 自证；test_ood 用初始值保证 M2 阶段 G0 可评，标定后重生成保证最终数据用标定值（60 [S14] 版本规则）
