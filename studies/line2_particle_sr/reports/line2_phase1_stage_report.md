## 1. 数据

**锚点与溯源**（`10` [S1]）。束源为 elegant 生成的 `injector.sdds`（200,001 × 6，float64，Charge = 5×10⁻¹⁰ C），
按用户批准入库于 `studies/line2_particle_sr/data/anchor/`，MD5 = `f39d905f96abd5588091dad6dd3884b2`；
`twiss.json` 与 `manifest.json` 随件入库，全部二十余项二阶矩/发射度/时间-能量统计量经独立重算核验
（最大相对误差 1.7×10⁻¹⁴，远优于 `10` [S1] C2 的 1×10⁻¹² 口径）。

**束群与传输**（`10` [S3]）。1000 束 = 1 个无抖动基准束（束 0）+ 999 束抖动束（焦斑漂移 ±5%、偏角 1×10⁻⁵ rad、
漂移段 495–505 mm）；抖动参数由 `SeedSequence(20260913)` 派生，与束号一一对应。传输用 Ocelot 的 FODO
（n_cells = 2、μ = 75°/cell、漂移 2.5 m、四极长 0.1 m），两站各 200,001 粒子守恒。相位推进的标定用**实算二分**
（μ 实算偏差 ~1×10⁻¹³°），薄透镜闭式公式仅作初值——该细化已登记（`10` D3）。

**数据集体**（`10` [S4]/[S5]）。束级切分 700/150/150（train/val/test，`SeedSequence` 派生、互斥完备）；
五档输入 N ∈ {1×10³, 3×10³, 1×10⁴, 3×10⁴, 1×10⁵} × 每档 k = 20 个**无放回**子样本（严格 A ⊂ B），
目标恒为同束同站的 2×10⁵ 全量六投影直方图；六投影按 `00` [S1] 枚举顺序、图内布局 [后一坐标, 前一坐标]、
int32 128²、∑counts 严格等于该档粒子数。落盘 `studies/line2_particle_sr/data/line2_ds_v1/`，5.5 GB
（train 3.88 / val 0.83 / test 0.83），构建耗时 75 min，`manifest.json` 记 GC7 三元组与锚点 MD5。

**尺子（纯数据基线，与任何模型输出无关）**（`20` [S2]/[S4]、`40` [S1] E0）。
E0 裸误差–N 曲线在 **val+test 300 束 × 两站 × 五档 × k = 20** 上取中位数与 IQR（耗时 100.5 s），
一并与互差地板和**参照噪声地板 0.2856**（1×10⁵ 档配对 M1 差中位数 / √2）落盘；容差线表给出
13 项观测量 × 5 档的 95% 分位（耗时 461 s）。**E0 完成时间戳 04:11:22Z 早于 E1 任一 run 的启动
06:23:30Z**（`40` [S1] C5 的可验证顺序），且该顺序由编排器在启动前强制校验。

## 2. 设置

**两臂**（`30` [S1]/[S4]）。输入为逐投影自归一的 6 张形状图 + κ 条件向量，输出为逐投影和 = 1 的概率图
（Softplus + 归一化），损失用 Poisson NLL（率语义 rate = p·2×10⁵）。

| 变体 | 拓扑 | 参数量 | 条件向量 κ |
|---|---|---|---|
| 联合（joint） | 1 个 6 进 6 出 FiLM U-Net（base 48 / depth 4 / blocks 2）+ 软一致罚项 P_PSD | 10,708,710 | Σ 的 10 个唯一分量 + log₁₀N |
| 独立（independent） | 6 个 1 进 1 出单投影网（base 16 / depth 4 / blocks 3），权重互不共享 | 10,092,870（−5.8%） | (var_i, var_j, cov_ij, log₁₀N) |

κ 的两臂定义差异与尺度问题见 §6。训练配置（两臂逐字一致，仅变体与种子不同）：AdamW（lr 3×10⁻⁴、
wd 1×10⁻⁴）、batch 16、**max_steps = 50,000（预注册）**、每 1000 步评估、patience = 10、梯度裁剪 1.0、
早停与选型准绳 = val N_eff；单卡、确定性模式（`CUBLAS_WORKSPACE_CONFIG=:4096:8`，执行模式逐 run 记入 summary）。

**实验矩阵**（`40` [S1]/[S2]）。E0（尺子，先行）→ **E1**：两臂 × 5 种子 {100…104} @N_low = 1×10⁴、站 0
（10 runs，同种子成对）→ **E2**：获胜变体（由 E1 的 val 段按 `40` [S3] 路由规则**脚本化**决定，
不人工指定）× {3×10³, 1×10⁵} × 5 种子（10 runs）→ **E3**：获胜变体的 5 个 ckpt 直接应用于站 1 的 test 束
（不重训练）。E1/E2 的训练/评估成对落在 `results/<run_id>/`（`run_meta.json` 记启动/结束时间戳与 GC7 三元组）。

**评估口径**（`20` [S1]/[S3]、`40` [S3]）。test 束 × 站 0 × 该 run 的档位 × 子样本 0–19，逐 (束, 子样本)
推理后对子样本取 err 中位数 → 全束中位数 → 在 E0 曲线上做 log-N 线性插值反解 **N_eff**（报告域 [1×10³, 1×10⁵]，
越界即带上/下溢标记）；观测量用 `20` [S4] 的 13 维偏差向量与最近档容差线比对。

## 5. 设计理由（Why）

**为什么主指标是 N_eff 而不是 RMSE。** 超分的价值在于"用多少模拟成本换到同等精度"。
N_eff 把网络输出的形状误差在裸误差–N 曲线上反解成"等效的裸模拟粒子数"，于是结论直接读作
"1×10⁴ 颗的网络输出 ≈ X 颗裸模拟"，与实验成本同量纲、可被任何加速器同事复核。裸 RMSE 则依赖
束的具体标定，跨束不可比。

**为什么两臂必须参数量对齐、同种子、同步数。** H3 要回答的是"跨投影信息是否流动"这一件事，
对照变量必须唯一；任何参数量（±30%）、初始化随机性、步数预算的差异都会与拓扑效应混在一起
不可分离（GC4）。故 E1 的十份 config 除 (变体, 种子) 外逐字相同，并由测试自动断言；
五档与两站的原始样本完全同源（同一束、同一站、同一无放回子样本集）。

**为什么种子 ≥ 5 且必须同种子成对。** 单次训练的 seed 方差足以吞掉小幅增益，5 种子给出中位数与
极差；成对比较消除"种子运气"这一共同项，使 H3 的 5 对计数有判别力（`30` D5、`40` D10）。

**为什么尺子必须先于读数（E0 先行）。** N_eff 的定义依赖裸误差–N 曲线；若曲线可在看到模型结果之后
再定，任何阈值都能被事后调出来。把 E0 的完成时间戳固定在 E1 启动之前，并由编排器在启动前强制校验，
使"尺子先于读数"成为可验证事实而非承诺。

**为什么 test 只在出口门禁评一次。** 调参、选型、路由全部只消费 val 段；test 段一次评估用于出口门禁，
避免"看着 test 调参"的隐性过拟合（GC3 与 `40` [S3] 两段式）。

**为什么判据三分类而不是显著/不显著。** 5 对的样本量下任何形式化检验都功效不足；与其制造虚假的
统计强度，不如如实输出 {成立, 方向成立（仅 H3）, 不成立, 不可判定} 四个枚举，并把"不可判定"当作
正规结论（`40` D2/D4）。

## 6. 偏差、修复与局限

**执行期发现并修复的两个实测缺陷（均在 E1 首次有效启动之前完成，无已采信结果作废）。**

1. **图内轴向布局的生产者/消费者不一致**。生产端存 `h.T`（图内布局为 [后一坐标, 前一坐标]），
   而 M4 的 Σ 重构、κ 的矩摘要、P_PSD、B-moment 渲染均按 [前一, 后一] 解读。真值实验（40 万粒子、
   各轴量级互异）给出的 Σ 对角相对误差为 **−0.867 / +6.53 / +5.53 / −0.847**，修复后降到
   **8.5×10⁻⁵ … 5.8×10⁻⁴**（分箱量化地板）；真实锚点对 `twiss.json` 由 −7.0%…+15.3% 降到 ~6×10⁻⁴。
   该缺陷此前未被既有测试抓住，因为原合成云各轴 range/σ 相同、错配自抵消——新回归测试改用逐轴互异的
   粒子表，回退即翻红。**该修复同时更正了 `20` 决策 D13 的归因**（对角偏差的成因是轴向配对缺陷，
   不是"分箱物理极限 ~4.5%"；分箱地板实测 5.3×10⁻⁴–7.8×10⁻⁴），见 `20` D16。
2. **E1 配置两处**：① 两臂种子互不重叠（joint {0…4} / independent {100…104}），使 `40` [S3] 的
   "同种子成对比较"字面不可满足（按值配对 0 对）；② 独立臂 `num_levels=3` 使参数量掉到 2,476,230
   （联合的 −76.9%），破坏 H3 的公平性前提。二者已改为同组种子 {100…104} 与标定值（−5.8%），
   并加了自动断言（种子集合逐元素相同、参数量差 ≤30%）。见 `30` D11、`40` D10。

**偏差登记（未经用户裁决者，均在对应 `.decisions.md` 中留档）。**

- **κ 未做尺度归一 ⇒ 矩条件化与软一致罚项在生产档数值惰性**（`30` D13）。Σ 分量为**物理单位²**
  （实测 4.9×10⁻¹¹…1.2×10⁻⁷），而 log₁₀N ≈ 4.8：Σ 分量整体 ×100 只让输出变化 ~1.9×10⁻⁹；
  `P_PSD ≤ ~2.5×10⁻¹³` 对 NLL（0.6–21）无影响。**影响面**：H3 的结论只支持"共享主干带来的跨投影
  信息流动"这一条，不得表述为"PSD 软约束有效"；H1 的"物理先验"解读相应弱化。修复需重新设计 κ 的
  参数化（属预注册处理变更），会作废全部训练证据，故本轮登记不改。
- **κ 的 log₁₀N_low 分量口径 = 图组六投影总计数（= 6·N_low）**（`30` D14）。对同一档位是常量偏移
  （log₁₀6 ≈ 0.778，可被 FiLM 偏置吸收），不改变档间比较；仅影响"把 κ 末位当 log₁₀N_low 解读"的场合。
- **独立臂 κ 的第三分量是协方差而非相关系数**（`30` D17）。`30` [S4] 文字写 ρ_ij；实现取 cov_ij，
  与上一条的尺度惰性叠加。两臂 κ 的**实际**定义已如实记录。
- **Phase 1 训练为单卡路径，DDP 双卡冒烟缓期**（`30` D12）——`30` [S3] **C4 未满足**（非"缓期实现"），
  需在出口决策中单列。
- **`10` [S5] C2 的显式身份字段未落盘**（`10` D12）：`station`/`N_low`/`sub_idx` 由层级命名承载而非
  写成 attr，束 0（基准束）亦无 `jitter_*` 字段；身份在产物中完备且机读（由 `[S5]` C4/C5 用例断言），
  补字段可在 E1/E2 结束后地对 attr 原地补写。
- **判定域顶与平局**：N_eff 的报告域上端为 1×10⁵，而 2×10⁵ 才是目标总粒子数——模型在 1×10⁴ 输入下
  很快触顶（上溢语义 = 达到可验证域顶）。**后果**：H1 的"成立"是饱和成立；H3 若两臂同时触顶则逐对
  为平局，按 `40` [S3] 字面（"联合 ≥ 独立"）仍输出"成立"，但门禁与报告会同时披露 `n_ties`、
  `n_strict_joint_wins` 与 `tied_at_domain_edge`，明示该档不具备区分力。**H8 与 H1 可以同时给出
  "不成立"与"成立"**：后者是聚合形状误差（M1），前者是 13 项观测量逐项，且容差线按最近档映射落到
  最严的 1×10⁵ 档——两者度量不同的东西，不构成矛盾。
- **`10` [S3] C1 的标定路径**：若按 spec 字面的薄透镜公式反解会得到 77.35°（超 1° 容差），实现改用
  二分实算 75.00°；该细化已由 `10` D3 登记为良性细化，但 spec 文本的路径描述与实现不同名，出口决策
  时应知悉。

**已接受的既有偏差**：束 0 的 |Δcorr| = 0.1366 < 0.3（无抖动基准束在 FODO 后相关性变化不足），
`10` D11 已裁决接受，测试以 imperative xfail 留痕（束 1–5 全部 ≥ 0.3）。

## 7. 复现

```bash
# 0) 环境（唯一允许的两个环境之一；ocelot + sdds 已锁入 sr-sim）
source "$(conda info --base)/etc/profile.d/conda.sh" && conda activate sr-sim
python scripts/check_env.py

# 1) 数据集（若需重建；现成产物在 studies/line2_particle_sr/data/line2_ds_v1/）
python -m src.line2.data_pipeline.build_dataset --config <config>   # CLI 见该模块 main()

# 2) 尺子先行（E0 曲线 + 容差线表）
python -m src.line2.experiments.e0 --data-dir studies/line2_particle_sr/data/line2_ds_v1
python -m src.line2.experiments.tolerance_table

# 3) E1 十次训练（两卡各一条队列；E0 未完成则拒绝启动）
python -m src.line2.experiments.run_e1 train --runs e1_joint_s0 e1_joint_s1 e1_joint_s2 e1_joint_s3 e1_joint_s4 --gpus 0
python -m src.line2.experiments.run_e1 train --runs e1_indep_s0 e1_indep_s1 e1_indep_s2 e1_indep_s3 e1_indep_s4 --gpus 1

# 4) test 端评估（档位按各 run 的 run_meta）→ 路由 → E3 → 门禁 → 产出物
python -m src.line2.experiments.run_e1 eval --station 0 --subs 0-19 --device cuda:0
python -m src.line2.experiments.make_e2_configs --results-dir studies/line2_particle_sr/results
python -m src.line2.experiments.run_e1 eval --station 1 --subs 0-19 --device cuda:0 --runs <获胜变体 5 个 run>
python -m src.line2.experiments.run_e1 gates
python -m src.line2.experiments.map_report

# 5) 全量测试
python -m pytest -q
```

步骤 3–4 串成无人值守链（含依赖顺序校验与逐 run 时间戳落盘）。
