**数据集体**（`10` [S4]/[S5]）。束级切分 700/150/150（train/val/test，`SeedSequence` 派生、互斥完备）；
五档输入 N ∈ {1×10³, 3×10³, 1×10⁴, 3×10⁴, 1×10⁵} × 每档 k = 20 个**无放回**子样本（严格 A ⊂ B），

**尺子（纯数据基线，与任何模型输出无关）**（`20` [S2]/[S4]、`40` [S1] E0）。
E0 裸误差–N 曲线在 **val+test 300 束 × 两站 × 五档 × k = 20** 上取中位数与 IQR（耗时 100.5 s），
一并与互差地板和**参照噪声地板 0.2856**（1×10⁵ 档配对 M1 差中位数 / √2）落盘；容差线表给出

06:23:30Z**（`40` [S1] C5 的可验证顺序），且该顺序由编排器在启动前强制校验。

## 2. 设置

**两臂**（`30` [S1]/[S4]）。输入为逐投影自归一的 6 张形状图 + κ 条件向量，输出为逐投影和 = 1 的概率图
（Softplus + 归一化），损失用 Poisson NLL（率语义 rate = p·2×10⁵）。

| 变体 | 拓扑 | 参数量 | 条件向量 κ |
|---|---|---|---|
| 联合（joint） | 1 个 6 进 6 出 FiLM U-Net（base 48 / depth 4 / blocks 2）+ 软一致罚项 P_PSD | 10,708,710 | Σ 的 10 个唯一分量 + log₁₀N |
| 独立（independent） | 6 个 1 进 1 出单投影网（base 16 / depth 4 / blocks 3），权重互不共享 | 10,092,870（−5.8%） | (var_i, var_j, cov_ij, log₁₀N) |

κ 的两臂定义差异与尺度问题见 §6。训练配置（两臂逐字一致，仅变体与种子不同）：AdamW（lr 3×10⁻⁴、
wd 1×10⁻⁴）、batch 16、**max_steps = 50,000（预注册）**、每 1000 步评估、patience = 10、梯度裁剪 1.0、
早停与选型准绳 = val N_eff；单卡、确定性模式（`CUBLAS_WORKSPACE_CONFIG=:4096:8`，执行模式逐 run 记入 summary）。

**实际训练步数与选型点**（实测 `results/*/summary.json`）：`best_step` = joint **{3000, 2000, 2000, 3000, 2000}**、
independent **{1000, 1000, 1000, 2000, 1000}**；`steps` = joint **12k–13k**、independent **11k–12k**，
即 50,000 的预注册预算只用了 **22–26%**（两臂均值 22.4% / 24.8%）。根因是选型准绳 val N_eff
**从首个评估周期起即触顶**（`e1_indep_s0` 的 11 个评估周期 val N_eff 全为 100000.0），
`should_update_best` 用严格 `>` ⇒ 触顶后永不更新 ⇒ patience = 10 直接停机。三个后果与 Phase 2 待议项见 §6。

**实验矩阵**（`40` [S1]/[S2]）。E0（尺子，先行）→ **E1**：两臂 × 5 种子 {100…104} @N_low = 1×10⁴、站 0
（10 runs，同种子成对）→ **E2**：获胜变体（由 E1 的 val 段按 `40` [S3] 路由规则**脚本化**决定，
不人工指定）× {3×10³, 1×10⁵} × 5 种子（10 runs）→ **E3**：获胜变体的 5 个 ckpt 直接应用于站 1 的 test 束
（不重训练）。E1/E2 的训练/评估成对落在 `results/<run_id>/`（`run_meta.json` 记启动/结束时间戳与 GC7 三元组）。
**十个 E1 run 的 `code_version` 共四个取值**（`21aaedb`、`3cb412b`、`a122ec5`、`a7b3530`）：四者之间
**训练与评估的数值路径无改动**——`git diff 21aaedb a7b3530 -- src/line2/training src/line2/metrics` 只有
`independent.py` 的局部变量 `rho → cov_ij` 重命名（表达式逐字不变）与 docstring、以及 `train.py` 的
docstring `D16→D12`，`evaluate.py` 与 `metrics/*` 零改动；`21aaedb` 本身即轴向修复落地版，十个 run
全部包含它。故 `40` [S1] C3 的"config 逐字一致"仍成立、GC4 公平性不受影响。门禁代码
（`gates.py`/`run_e1.py`/`make_e2_configs.py`/`tolerance_table.py`）在后续版本有改动——不影响训练，
且门禁最终在 `306d396` 重跑并把该版本记入 `e1_gates.json`；因本轮整改后再次重跑门禁与评估，该字段
现为当时的 HEAD（`b758e57`）——它记录的是**判定代码版本**，各 run 的实际执行版本以 `run_meta.json`
为准；`tree_dirty` 的实测分布为 **E1 十个 run 无该字段、E2 八个 `false`、两个 `true`**
（`e2_joint_n3000_s0`/`s3`，两者均参与主曲线的 3×10³ 点）——`true` 意味着执行的代码不能由所记
`code_version`（`a7b3530`）唯一确定，已登入不可验证项（§6）。

**评估口径**（`20` [S1]/[S3]、`40` [S3]）。test 束 × 站 0 × 该 run 的档位 × 子样本 0–19，逐 (束, 子样本)
推理后对子样本取 err 中位数 → 全束中位数 → 在 E0 曲线上做 log-N 线性插值反解 **N_eff**（报告域 [1×10³, 1×10⁵]，
越界即带上/下溢标记）；观测量用 `20` [S4] 的 13 维偏差向量与最近档容差线比对。

## 3. 结果

本节的图件为 `studies/line2_particle_sr/reports/figure_avail_domain.png`（**方法可用域地图**）：
面板 A 画放大比 `N_eff/N_low` vs `N_low`（log-log，含可验证域带、`N_eff = N_low` 的无放大线、以及
`N_eff = 1×10⁵` 的域顶线），面板 B 画裸 M1 vs N（含参照噪声地板线）并叠加本模型的 err 中位数落点；
N_eff 与误差的数值明细见 `studies/line2_particle_sr/results/n_eff_table.csv`。

**E1（两臂 × 5 种子 @N_low = 1×10⁴、站 0）**——N_eff 明细见 `studies/line2_particle_sr/results/n_eff_table.csv`。

| 变体 | 种子 | 该 run 的 test err 中位数 | N_eff | 标记 |
|---|---|---|---|---|
| joint | 100 / 101 / 102 / 103 / 104 | 0.2548 / 0.2811 / 0.2664 / 0.2259 / 0.2632 | 1×10⁵（全 5 个） | overflow |
| independent | 100 / 101 / 102 / 103 / 104 | 0.2849 / 0.2818 / 0.2751 / 0.2218 / 0.2755 | 1×10⁵（全 5 个） | overflow |

**E3（获胜变体 = joint 的 5 个 ckpt 直接应用于站 1 的 test 束）**：err 中位数
0.2444 / 0.2739 / 0.2366 / 0.2087 / 0.2363，N_eff 同样全为 1×10⁵（overflow）。

**读法**。E0 尺子给出裸误差–N 曲线 **4.030 / 2.316 / 1.246 / 0.680 / 0.286**（N = 1×10³…1×10⁵）
与参照噪声地板 **0.2856**；两臂在站 0 与站 1 的 test 形状误差（0.209–0.285）**全部落在 1×10⁵ 档裸误差
（0.2856）之下**，故按 `20` [S3] 的插值定义一律触到报告域顶（上溢语义 = 达到可验证域顶，即 1×10⁴ 工况的 10×）。
换言之：**在 1×10⁴ 输入下，网络输出已等价于 ≥1×10⁵ 颗裸模拟的精度**，而该档位本身不再有分辨力。

**网络不是字面常数解**：模型逐束 err 的标准差仅 **0.0021–0.0063**，而零信息常数解（下述均值束）的逐束
err 标准差为 **0.0870**（相差 14–41 倍）——常数解的误差随束剧烈变化，模型的误差几乎与束无关，故其输出
逐束不同，不是"把同一张图交给所有束"的退化解。对 `20` [S5] 冻结基线族它也大幅领先：B-raw @1×10⁴
= **1.2477**、B-moment @1×10⁴ = **1.5908**（两者按 test 束 × sub00 口径复算；E0 节点 1.2455 为
val+test 全子样本中位数），而全部 run 的 err 中位数为 0.22–0.29 ⇒ 对 B-raw 约 4.3–5.6 倍、
对 B-moment 约 5.5–7.2 倍。

**但一个零信息常数解给出更低的误差，"这不是输出平均束能得到的分数"这一读法不成立**：该常数解 =
**700 个 train 束目标图的均值图**（只用 train 划分构造、不接触 test；逐投影按参照总计数归一后按
`20` [S1] M1 评价），对 150 个 test 束的 err 中位数为 **0.194398**（逐束标准差 0.0870，范围
0.0958–0.3612），**优于全部 20 个 run 的 test err 中位数（0.2218–0.2898）**；且 0.194398 < 1×10⁵ 档
裸误差 **0.285636** ⇒ 该常数解的 N_eff 同样是 1×10⁵ / `overflow`，**同样满足 H1 的冻结判定表达式、
同样在 H3 上构成域顶平局**。模型只在 **40–69 / 150** 束上优于该常数解（逐束比值中位 **1.14–1.48**）。
该常数解的数值依赖 train 子集选取——仅用前 200 个 train 束 ⇒ 0.2104，结论不变（仍优于全部 run）。

**结论的口径**：H1 的"成立"只说明"网络在聚合形状误差（M1）上达到 ≥10×（3×10³ 档 ≥33×）的等效精度"，
**不能**读作"网络恢复了束特异结构"——在冻结的 M1 口径下，一个零信息常数解给出比全部 run 更低的误差。
该对照不在 `20` [S5] 冻结基线族内（见 §6 局限）。跨站结果见 §4 的 H7：ρ = 1.0，但两侧域顶截断使其
不可辨识。

**E2（joint × {3×10³, 1×10⁵} × 5 种子，2026-09-14T16:10:45Z 启动 → 2026-09-14T23:22:22Z 训练完成
（20 份 `run_meta.completed_at` 的最大值）→ 2026-09-14T23:53:42Z 全链（评估 + 门禁 + 报告）完成；
末项取自链日志的本地时刻 `07:53:42`（+0800），等价 UTC = 23:53:42Z）**：
十个 run 的站 0 test 结果与 E1 合并成三点放大主曲线——**放大比 `N_eff/N_low` 随 N_low 单调下降，
但三点中只有 1×10⁵ 档含非饱和点**：

| N_low | 变体 | run 数 | 放大比中位数 | 范围 | 上溢 | 该档 err 中位数 |
|---|---|---|---|---|---|---|
| 3×10³ | joint | 5 | **33.3×** | [33.3, 33.3] | 5/5 | 0.2780 |
| 1×10⁴ | joint | 5 | **10×** | [10, 10] | 5/5 | 0.2632 |
| 1×10⁴ | independent | 5 | 10× | [10, 10] | 5/5 | 0.2755 |
| 1×10⁵ | joint | 5 | **1.0×** | [0.987, 1.0] | 4/5 | 0.2633 |

**读法**：观测越稀疏、等效放大越大（3×10³ 输入下 ≥33×、1×10⁴ 下 ≥10×）——但这两档的中位放大比
**恰等于 1×10⁵/N_low**（33.3333 = 100000/3000、10.0000 = 100000/10000），即它们由域顶 1×10⁵ 与
N_low 之比**构造**得出、分辨力为零，不构成独立的放大测量；33× 亦超出 `00` [S1] 声明的"可验证放大
上限 = 10×"叙事边界（图内域顶线与报告域的披露见 §3 开头与 §6）。到 1×10⁵ 档放大比回落到 1.0
附近——该档本身已接近尺子高端，网络只需"维持"而非"放大"。1×10⁵ 档的 5 个 run 中有 1 个（`e2_joint_n100000_s2`，
err 0.2898 > 该档裸误差 0.2856）**未触顶**，给出真实插值值 **N_eff = 98,724（无标记）**，其余 4 个触顶——
即该档是三点中唯一出现非饱和点的位置，也正是曲线右端可信度的直接证据。

## 4. 门禁结论

E1 段的出口门禁（`studies/line2_particle_sr/results/e1_gates.json`，全部由脚本从落盘产物判定、无人工裁量；
门禁的消费维度按 `40` [S3] 固定为 test 束 × 站 0 × N_low = 1×10⁴，故 E2 加入后四条结论不变）：

| 门禁 | 结论 | 判定表达式的输入数值快照 |
|---|---|---|
| **H1 放大存在性** | **成立** | 获胜变体 joint @1×10⁴ 的 5 种子 test N_eff = {100: 1e5, 101: 1e5, 102: 1e5, 103: 1e5, 104: 1e5}；中位数 1e5 ≥ 2e4 且 5/5 > 1e4。**饱和成立**（域顶） |
| **H3 联合 vs 独立** | **成立** | 5 对同种子比较 joint_wins = 5/5。**但 5 对全为域顶平局**：`n_ties = 5`、`n_strict_joint_wins = 0`、`tied_at_domain_edge = true`（两臂 10 个 N_eff 全部 `overflow`）。故该"成立"是 `40` [S3] 字面规则（平局计入 ≥）的结果，**不表示联合严格更优**，1×10⁴ 档不具备区分力；E2 加入后该判定不变（E2 的 3e3/1e5 评估按档位不进门禁） |
| **H7 跨站泛化（E3）** | **不可判定** | ρ = 1.0、`rho_median = 1.0`（种子中位数之比），但站 0 与站 1 两侧全部 5 个种子均携带 `overflow` ⇒ 按 `40` [S2]"上/下溢使 ρ 无法计算 → 不可判定"判定；`reason_code = n_eff_flag_present`。**原始证据（ρ 恰为 1.0、站 1 误差中位数 0.2366 与站 0 的 0.2632 同量级甚至更低）指向无明显跨站衰减**，但域顶截断使该结论不可辨识，故按预注册规则如实判"不可判定" |
| **H8 细结构可恢复性** | **不成立** | 150 束 × 13 观测量的达标率 = **0.1318 ≤ 0.50**；容差线按每束 N_eff（= 域顶）映射到 **1×10⁵ 档**（`tolerance_tier_mode = 100000`、档位分布 `1e5×150`，即全部 150 束都落到最严档）——该档是判定表达式的输入，已随门禁落盘（`40` [S4] C2）；聚合顺序为"逐观测量先对 5 种子取中位数再判达标"（`20` [S4]） |

**变体路由（E2 用）**：由 E1 的 **val 段**按 `40` [S3] 规则脚本化决定，
`studies/line2_particle_sr/results/e2_routing.json` 记 `winner_variant = joint`、`basis = val`、
按种子值配对（`[[100,100],…]`）、`n_pairs = 5`；val 段两臂中位数 **同为 1×10⁵（域顶平局）**，
按"联合 ≥ 独立"计入胜选 joint。**该路由建立在平局之上，且 E2 只训练了获胜变体**——因此本阶段
**无法在 3×10³ 档复核这个选择**（没有独立臂 @3×10³ 的对照）。这是 Phase 1 的一项结构性局限：
H3 的"成立"不构成"联合更优"的证据，两点之间也不存在可用于事后校验的对照臂。

**H1 与 H8 可以同时给出"成立"与"不成立"**：前者是聚合形状误差（M1，网络误差已低于 1×10⁵ 颗裸模拟），
后者是 13 项物理观测量逐项（`20` [S4] 的 13 项 = M4 的 11 维 + M5 + M6，**不含 M2 分桶项**，故暗桶
不参与达标率；容差线按每束 N_eff 映射到最严的 1×10⁵ 档）。两者度量
不同的对象，不构成矛盾，但**共同说明"整体形状恢复得好"不等于"每项物理量都达到等效 1×10⁵ 颗裸模拟的
细结构精度"**——这正是 H8 被单列的原因；按档位敏感性实测，同一组观测量若改用 1×10⁴ 档容差则达标率
为 0.9836（成立），故 H8 的"不成立"直接由"网络已把 N_eff 推到域顶、容差随之落到最严档"决定。

**H8 的暗桶分项**：`40` [S3] 要求暗桶（B0/B1）的 M2 相对改进**单独报告、不并入达标率**；13 维观测量
里没有 M2 分桶项，故该分项是达标率之外的独立一列（本节数值落于 `results/e1_gates.json` 的
`H8.dark_bucket_m2`，同一段由 `phase1_report.md` 的 H8 小节渲染）。5 个 joint run × 站 0 @1×10⁴ × 150 束、
逐束先对 5 种子取中位数：

| 桶 | 裸输入 M2 中位 | 模型 M2 中位 | 相对改进 |
|---|---|---|---|
| B0（参照计数 < 0.5） | **0.0（结构性恒零）** | 0.306068 | 无定义（裸为零） |
| B1（0.5 ≤ 参照 < 2） | 4.353628 | 0.817476 | **81.2%** |
| B0+B1 等权 | 2.176814 | 0.561037 | **74.2%** |

**读法（含一条新发现）**：B1（暗而非常空的桶）上网络相对裸输入把 M2 相对误差压低 81%，说明它在
**计数稀少的真实结构**上确有效用。但 **B0 的裸输入必然为 0**——子样本是全量粒子集的子集，参照零格在
子样本中亦为零，故该桶的"相对改进"无定义（不伪造 ∞）；而模型在 B0 上仍有 0.306 的绝对 M2，即
**在参照空区产生了幻觉性计数**。这与 H8 达标率 13.18% 的不成立并不矛盾：两者度量的对象不同
（前者是分桶 M2 相对改进、后者是 13 项观测量的容差达标率），`40` [S3] 要求并列报告正是为了让
"暗桶幻觉 vs 亮核保守"可分开读。

三点主曲线、门禁快照与逐束明细的可复现版本见同目录 `phase1_report.md`（由 `map_report` 一键生成，
同输入逐位一致），图件为 `figure_avail_domain.png`。

## 5. 设计理由（Why）

**为什么主指标是 N_eff 而不是 RMSE。** 超分的价值在于"用多少模拟成本换到同等精度"。
N_eff 把网络输出的形状误差在裸误差–N 曲线上反解成"等效的裸模拟粒子数"，于是结论直接读作
"1×10⁴ 颗的网络输出 ≈ X 颗裸模拟"，与实验成本同量纲、可被任何加速器同事复核。裸 RMSE 则依赖
束的具体标定，跨束不可比。

**为什么两臂必须参数量对齐、同种子、同步数。** H3 要回答的是"跨投影信息是否流动"这一件事，
对照变量必须唯一；任何参数量（±30%）、初始化随机性、步数预算的差异都会与拓扑效应混在一起
不可分离（GC4）。故 E1 的十份 config 除 (变体, 种子) 外逐字相同，并由测试自动断言；
五档与两站的原始样本完全同源（同一束、同一站、同一无放回子样本集）。

**为什么种子 ≥ 5 且必须同种子成对。** 单次训练的 seed 方差足以吞掉小幅增益，5 种子给出中位数与
极差；成对比较消除"种子运气"这一共同项，使 H3 的 5 对计数有判别力（`30` D5、`40` D10）。

**为什么尺子必须先于读数（E0 先行）。** N_eff 的定义依赖裸误差–N 曲线；若曲线可在看到模型结果之后
再定，任何阈值都能被事后调出来。把 E0 的完成时间戳固定在 E1 启动之前，并由编排器在启动前强制校验，
使"尺子先于读数"成为可验证事实而非承诺。

**为什么 test 只在出口门禁评一次。** 调参、选型、路由全部只消费 val 段；test 段一次评估用于出口门禁，
避免"看着 test 调参"的隐性过拟合（GC3 与 `40` [S3] 两段式）。**设计与执行有差距**：派发端未强制
"只评一次"，链日志中同一 (run, 站, 档) 被派发 2–3 次、产物由最后一次覆盖写；本次无数值损害，但属
机制缺失（修法已落地：目标产物已存在时默认跳过、`--force` 才覆盖，并逐次写 `eval_history.jsonl`
留痕），见 §6 的不可验证项。

**为什么判据三分类而不是显著/不显著。** 5 对的样本量下任何形式化检验都功效不足；与其制造虚假的
统计强度，不如如实输出 {成立, 方向成立（仅 H3）, 不成立, 不可判定} 四个枚举，并把"不可判定"当作
正规结论（`40` D2/D4）。

## 6. 偏差、修复与局限

**执行期发现并修复的两个实测缺陷（均在 E1 首次有效启动之前完成，无已采信结果作废）。**

1. **图内轴向布局的生产者/消费者不一致**。生产端存 `h.T`（图内布局为 [后一坐标, 前一坐标]），
   而 M4 的 Σ 重构、κ 的矩摘要、P_PSD、B-moment 渲染均按 [前一, 后一] 解读。真值实验（40 万粒子、
   各轴量级互异）给出的 Σ 对角相对误差为 **−0.867 / +6.53 / +5.53 / −0.847**，修复后降到
   **5.7×10⁻⁵ … 5.8×10⁻⁴**（分箱量化地板）；真实锚点对 `twiss.json` 由 −7.0%…+15.3% 降到 ~6×10⁻⁴。
   该缺陷此前未被既有测试抓住，因为原合成云各轴 range/σ 相同、错配自抵消——新回归测试改用逐轴互异的
   粒子表，回退即翻红。`20` D13 的归因已由 `20` D16 更正（D13 在日志中标为 superseded；
   对角偏差的成因是轴向配对缺陷，不是"分箱物理极限 ~4.5%"；分箱地板实测 5.3×10⁻⁴–7.8×10⁻⁴）。
2. **E1 配置两处**：① 两臂种子互不重叠（joint {0…4} / independent {100…104}），使 `40` [S3] 的
   "同种子成对比较"字面不可满足（按值配对 0 对）；② 独立臂 `num_levels=3` 使参数量掉到 2,476,230
   （联合的 −76.9%），破坏 H3 的公平性前提。二者已改为同组种子 {100…104} 与标定值（−5.8%），
   并加了自动断言（种子集合逐元素相同、参数量差 ≤30%）。见 `30` D11、`40` D10。

**偏差登记（裁决状态逐条见 `10`/`30`/`40` 的 `.decisions.md`：`10` D11 已裁决接受，
`10` D12、`30` D12/D13、`30` D17、`40` D14 待验收闸口裁决；本批新登记的 `40` D15–D18 与 `30` D20/D21
见各自日志）。**

- **κ 在 Phase 1 全部 11 维无信息量 ⇒ FiLM 条件化等价于一个偏置**（`30` D13，影响面由 `30` D20 更正）。
  κ 的前 10 维是**物理单位²**的 Σ 分量，量级 **5.6×10⁻¹¹…1.2×10⁻⁷**；第 11 维 = `log₁₀(counts.sum())`
  = log₁₀(6·N_low)——每个 run 的训练集只有单档（`Line2Pairs(n_low=…)`）且 ∑counts 恒 = 6·N_low，
  故该维在**整个 run 内是常数**（3×10³ → 4.255273、1×10⁴ → 4.778151、1×10⁵ → 5.778151）。
  即 10 维数值惰性 + 1 维恒定，条件向量不携带任何可用信号；`P_PSD ≤ ~2.5×10⁻¹³` 对 NLL（0.6–21）
  亦无影响。**影响面**：H3 的结论只支持"共享主干带来的跨投影信息流动"这一条，不得表述为
  "PSD 软约束有效"或"FiLM 矩条件化有效"；H1 的"物理先验"解读相应弱化；**跨站鲁棒性不能归因于
  条件化**。修复需重新设计 κ 的参数化（属预注册处理变更），会作废全部训练证据，故登记为偏差、
  暂不改实现。
- **选型准绳饱和 ⇒ 全部 20 个 run 早停于预算的 22–26%**（实测 `results/*/summary.json`、
  `train_log.jsonl`）。`best_step` = joint {3000, 2000, 2000, 3000, 2000}、independent
  {1000, 1000, 1000, 2000, 1000}；`steps` = joint 12k–13k、independent 11k–12k（预算 50,000 的
  22–26%，两臂均值 24.8% / 22.4%）。根因：val N_eff 从首个评估周期即触顶（`e1_indep_s0` 的 11 个
  周期全为 100000.0），`should_update_best` 的严格 `>` 使其后永不更新，patience = 10 直接停机。
  **三个后果**：① `30` [S3] C2 的"最优周期"在饱和下**语义空洞**——它是 10 个并列值中最早到达的那
  一个；② **被评估的 ckpt 不是训练最充分的**——`e1_joint_s0` 的选型点停在 **step 3000**
  （train_nll 0.802945），而训练继续到 step 13000 时 train_nll 已降到 0.622167（比被选中的 ckpt
  低 22.5%）、val_nll 亦从 0.805 降到 0.623——即选型冻结后模型仍显著改善，但那些周期的权重不再被
  采用；③ **两臂实际步数不等**（joint 比 independent
  多跑 8–18%，逐 run 配对比值 1.08–1.18），而 H3 恰是 5/5 域顶平局、0 严格胜——两件事叠加使 H3
  更加无从解读。**Phase 2 需重议选型准绳**（N_eff 饱和后改用次级准绳，如 val NLL 或 val err）。
- **零信息常数解优于全部 run，且不在 `20` [S5] 冻结基线族内**。该基线族 = B-raw / B-curve / B-moment，
  缺"零信息常数解"这一族；本批实测（§3）700 个 train 束目标均值图对 test 束的 M1 中位数
  **0.194398**，优于全部 20 个 run（0.2218–0.2898），且 0.194398 < 1×10⁵ 档裸误差 0.285636 ⇒ 同样
  触发 N_eff 上溢、同样满足 H1 的冻结判定表达式。属 spec 层缺口，已按 `00` [S4] 的登记规则立条目
  （`40` D18，指针指向 `20` [S5]）；后续阶段应把该族补入基线族。
- **κ 的 log₁₀N_low 分量口径 = 图组六投影总计数（= 6·N_low）**（`30` D14）。对同一档位是常量偏移
  （log₁₀6 ≈ 0.778，可被 FiLM 偏置吸收），不改变档间比较；仅影响"把 κ 末位当 log₁₀N_low 解读"的场合。
- **独立臂 κ 的第三分量是协方差而非相关系数**（`30` D17）。`30` [S4] 文字写 ρ_ij；实现取 cov_ij，
  与上一条的尺度惰性叠加。两臂 κ 的**实际**定义已如实记录。
- **Phase 1 训练为单卡路径，DDP 双卡冒烟缓期**（`30` D12）——`30` [S3] **C4 未满足**（非"缓期实现"），
  需在出口决策中单列。
- **`10` [S5] C2 的显式身份字段未落盘**（`10` D12）：`station`/`N_low`/`sub_idx` 由层级命名承载而非
  写成 attr，束 0（基准束）亦无 `jitter_*` 字段；身份在产物中完备且机读（由 `[S5]` C4/C5 用例断言），
  补字段可在 E1/E2 结束后地对 attr 原地补写。
- **判定域顶与平局**：N_eff 的报告域上端为 1×10⁵，而 2×10⁵ 才是目标总粒子数——模型在 1×10⁴ 输入下
  很快触顶（上溢语义 = 达到可验证域顶）。**后果**：H1 的"成立"是饱和成立；H3 若两臂同时触顶则逐对
  为平局，按 `40` [S3] 字面（"联合 ≥ 独立"）仍输出"成立"，但门禁与报告会同时披露 `n_ties`、
  `n_strict_joint_wins` 与 `tied_at_domain_edge`，明示该档不具备区分力。**H8 与 H1 可以同时给出
  "不成立"与"成立"**：后者是聚合形状误差（M1），前者是 13 项观测量逐项，且容差线按最近档映射落到
  最严的 1×10⁵ 档——两者度量不同的东西，不构成矛盾。
- **`10` [S3] C1 的标定路径**：若按 spec 字面的薄透镜公式反解会得到 77.35°（超 1° 容差），实现改用
  二分实算 75.00°；该细化已由 `10` D3 登记为良性细化，但 spec 文本的路径描述与实现不同名，出口决策
  时应知悉。

**不可验证项**（`00` C4/C7 的覆盖缺口见各自 decisions 登记，本报告不含自造测试）：

- **两个 run 以 `tree_dirty = true` 执行**：`e2_joint_n3000_s0`/`s3`（`code_version = a7b3530`）——执行的
  代码不能由所记版本唯一确定（`40` D17）。两者均参与主曲线的 3×10³ 点（33.3×）。
- **站 0 test 评估曾被重复派发**：同一 (run, 站, 档) 被派发 2–3 次（`phase1_chain.log` 15 次、
  `phase1_e2_chain.log` 40 次，含 `e1_indep_s0` 与 `e1_joint_s0` 各两次），20 份 `test_eval.json` 由
  最后一次覆盖写，首次写入的版本已不可查。**本次无数值损害**——`git diff a7b3530 306d396 --
  src/line2/experiments/evaluate.py src/line2/metrics src/line2/training src/line2/data_pipeline` 为空，
  且确定性测试钉住逐位可复现——但这是运气而非机制（`40` D16；派发端修法已落地，见 §5）。
- **确定性口径的两处证据强度**：`10` D12 的替代契约只覆盖一个示例路径；`30` D18 的 GPU 侧
  "val N_eff 轨迹相对偏差 < 0.5%"容差分支从未被实测行使（GPU 确定性靠 `exec_mode` 留痕而非重训对拍）。

**已接受的既有偏差**：束 0 的 |Δcorr| = 0.1366 < 0.3（无抖动基准束在 FODO 后相关性变化不足），
`10` D11 已裁决接受，测试以 imperative xfail 留痕（束 1–5 全部 ≥ 0.3）。

## 7. 复现

```bash
# 0) 环境（唯一允许的两个环境之一；ocelot + sdds 已锁入 sr-sim）
source "$(conda info --base)/etc/profile.d/conda.sh" && conda activate sr-sim
python scripts/check_env.py

# 1) 数据集（若需重建；现成产物在 studies/line2_particle_sr/data/line2_ds_v1/）
python -m src.line2.data_pipeline.build_dataset \
    --out studies/line2_particle_sr/data/line2_ds_v1 --n-beams 1000 \
    --data-version line2_ds_v1          # 其余参数（--anchor-dir/--master-seed）见 --help

# 2) 尺子先行（E0 曲线 + 容差线表）
python -m src.line2.experiments.e0 --data-dir studies/line2_particle_sr/data/line2_ds_v1
python -m src.line2.experiments.tolerance_table

# 3) E1 十次训练（两卡各一条队列；E0 未完成则拒绝启动）
python -m src.line2.experiments.run_e1 train --runs e1_joint_s0 e1_joint_s1 e1_joint_s2 e1_joint_s3 e1_joint_s4 --gpus 0
python -m src.line2.experiments.run_e1 train --runs e1_indep_s0 e1_indep_s1 e1_indep_s2 e1_indep_s3 e1_indep_s4 --gpus 1

# 4) test 端评估（档位按各 run 的 run_meta）→ 路由 → E3 → 门禁 → 产出物
python -m src.line2.experiments.run_e1 eval --station 0 --subs 0-19 --device cuda:0
python -m src.line2.experiments.make_e2_configs --results-dir studies/line2_particle_sr/results
python -m src.line2.experiments.run_e1 eval --station 1 --subs 0-19 --device cuda:0 --runs <获胜变体 5 个 run>
python -m src.line2.experiments.run_e1 gates
python -m src.line2.experiments.map_report

# 5) 全量测试
python -m pytest -q
```

步骤 3–4 串成无人值守链（含依赖顺序校验与逐 run 时间戳落盘）。
