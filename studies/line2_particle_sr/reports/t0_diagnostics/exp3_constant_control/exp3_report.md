# T0-实验 3：网络 vs 零信息常数解的逐束配对分析与个性回归

line2 Phase 1 诊断；只读 `studies/line2_particle_sr/{data,results}`，
常数解口径照抄 `reports/tools/compute_phase1_numbers.py`
（700 train 束 station0/target_full 逐投影总计数归一后取均值 → 150 test 束 M1）。

## 1 判定

- **预注册判据成立（5/5 joint 种子 ρ 的 95% CI 全为正、5/5 种子 top 四分位赢率 > bottom）——但它不构成“网络提取个体信息”的证据**：该判据的两个条件都能被机械复现（§3）。
- **严格复读机假设（输出与输入无关的常数图）已被否证**：20/20 个 run 的逐束误差上界低于任何固定图的下界 (D_max/2 = 0.3337)，即网络输出确实随输入束变化（§4）。
- 但网络没把这种依赖性换成更低的误差：全部 20 个 run 的**中位误差都劣于常数解**（中位 advantage 全为负、Wilcoxon 全显著），只在离族均值最远的束上取胜。
- 综合：**“个体信息真实存在” 与 “复读机假设成立” 都不能按原判据下结论**（判据退化，见 §3）；可确证的只是“输出随输入变化”这一弱命题。

- 观测 ρ 中位 +0.576；**机械零假设**（把每个 run 的逐束误差换成其常数中位值，即“误差水平固定、对束无差别”）给出 ρ 中位 +0.576，与观测的最大偏差仅 0.009；top 四分位赢率的最大偏差 0.054。即：**预注册判据的两个条件都被该机械零假设精确复现**。
- 机制（决定性）：advantage 与 err_const 的 Spearman 中位 +0.9993（最小 +0.9985）——advantage 几乎是 err_const 的单调函数；而 err_const 随抖动幅度上升（ρ = +0.576, p = 1.2e-14）。模型逐束误差本身也只跟踪 err_const 的 +0.83 相关、斜率对应 4.2% 的变化幅度（std 0.00367 vs 0.08702）。⇒ “网络在个性强的束上赢” 等价于 “族均值在个性强的束上更差”，与网络是否使用个体信息无关。

## 6 度量噪声底：为什么“常数解更好”主要是度量问题

- `e0_curve.json` 的 `reference_noise_floor` = 0.2856（1e5 档配对 M1 中位数 / √2（独立同分布样本与参考之间的固有噪声距离））；折算到 test 用的 2e5 参考图，其自身计数噪声在 M1 下的固有距离约 0.2019。
- 常数解逐束误差中位 0.1944，与之同量级 ⇒ 常数解的误差几乎全部来自参考图自身的计数噪声，其“形状失配”项在该度量下可忽略；20 个 run 的中位误差 0.2218–0.2898 则高于该噪声底。
- 因此 M1 在这一分辨率上无法区分“复现了个体结构”与“给出了最光滑的先验图”：要把两者分开，需要看模型输出相对先验的增量与目标相对先验的增量之间的投影（`⟨out − prior, target − prior⟩`，本轮未做——需对 ckpt 逐束推理）。

## 7 种子一致性与 5 种子聚合

- 20 个 run 的 advantage 向量两两 Spearman（120 对）中位 +0.999（min +0.996 / max +1.000）；5 个 joint 种子内部中位 +0.999。
- 5 种子平均 advantage 的 ρ = +0.576 CI [+0.461, +0.676]（此为 5 种子聚合检验，与逐 run 结论一致）。

## 8 口径与偏差说明

- 常数解逐束误差本次独立重算，与 `reports/tools/phase1_numbers.json` 的 `const_errs` 逐元素最大偏差 0.0e+00（完全一致）。
- `jitter_f_j = 10·(1 + jitter_delta)` 与 `jitter_delta` 完全共线（`transport.py` 由 delta 派生），5 属性 L2 会把 delta 方向加权两次；主结论用 4 自由度版本，5 属性版本见 JSON。
- 每个束的 `target_full` 有**自己的 bin_edges**（`station_edges` 用该站全量粒子表的逐轴 min/max 外扩 1%），即图像是“自身尺度归一”的；150 个 test 束之间的窗口差异对 x/y 轴 < 0.05%、对 xp/yp 轴达 ±1–2.6%。
- 评测口径为 `group_rel_rmse`（六投影各归一后相对 RMSE 再平均）逐束结果，模型侧取 20 个子样本的中位数（`test_eval.json` 的 `per_beam[].err`），常数解与输入无关故单值即中位。
- 20 个 run 的 advantage 向量两两 Spearman 中位 +0.999（§7）说明“赢哪几束”在所有 run 之间几乎相同，即该模式是束（err_const）的性质，而不是某个 run 的行为。

## 9 结论与建议的下一步

1. 预注册判据在本实验上**退化**：它实际测的是 `ρ(err_const, 抖动幅度) = +0.576`，而不是模型的任何性质。建议在后续 Q/C 类实验中改写判据——例如以“advantage 对 err_const 的偏相关”“top 四分位内的绝对误差是否低于常数解在该四分位的中位误差”等条件替换，或在设计上先按束个性分层再比较。
2. 真正能分开两个假设的实验（本轮未做，属新范围）：对 ckpt 逐束推理，计算模型输出相对先验的增量与目标相对先验的增量之间的投影 `⟨out − prior, target − prior⟩`（先验 = 常数解图，逐投影归一后）及其与抖动幅度的关系；再配一个“先验打乱”对照（把另一束的输入喂给模型）以排除“输出只依赖输入的整体尺度”的解释。ckpt 在本机 `studies/line2_particle_sr/results/<run>/best_val.ckpt`（纯 CPU 推理可行，需先确认模型规模与耗时）。
3. M1 度量本身在本分辨率已触到参考图计数噪声底（§6）。若目标是判别“是否复现个体结构”，建议增设一个对噪声不敏感的结构型指标（如相对先验增量的相关性/方向余弦），而非继续比较 M1 的绝对值。
