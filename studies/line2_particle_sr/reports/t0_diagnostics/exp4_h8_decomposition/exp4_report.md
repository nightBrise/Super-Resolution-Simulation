# T0 实验 4：H8 十三项观测量误差的偏差/方差解剖

对象：line2 Phase 1 门禁 H8（test 束 × 站 0 × 1e4 × 5 种子中位数 → 13 项观测量对容差线的达标率）。
数据：`results/` 的 20 个 run（10 个 E1 = joint/independent 各 5 种子；10 个 E2 = 3e3/1e5 各 5 种子）、
`results/tolerance.json`、`data/line2_ds_v1`。**只读分析，纯 CPU**。

产物：本目录（脚本 `exp4_decompose.py` / `exp4_bare_floor.py`，数据表 `exp4_*.csv`，汇总 `exp4_summary.json` / `exp4_bare_floor.json`）。

## 1. 判定：混合，且可分层说清——同一模型内是偏移，跨模型实例才是方差

偏差/方差结论**随统计层变化**，三层必须分开读（同批数据，只是聚合方式不同）：

| 层 | 对象 | 基线达标率 | 偏移主导项数（r<0.238 判据／偏差份额>0.5 判据） | oracle 校准后达标率 | 预注册规则的字面结论 |
|---|---|---|---|---|---|
| L1a 逐 run（单次推理内 150 束，10 个 E1 run） | 校准实际作用的对象 | joint 种子均值 0.269（0.060–0.505）；independent 0.540（0.363–0.725） | **12/13** ／ 13/13 | 逐 run 常数 0.967 | 偏移主导可救 |
| L1b (run, 束) 池化 1500 对 | 跨 run 水平混合 | 0.404 | 1/13 ／ **6/13** | 单组 13 常数 0.683 | **方差主导需真改进**（按"方差项占多"分支） |
| L2 H8 判定口径（joint 5 种子中位数） | 门禁所见 | **0.1318** | **12/13** ／ **13/13** | **0.9723** | 偏移主导可救 |

同一判据在 L1a 与 L1b 给出相反结论，差别**全部来自跨 run 的水平散布**：单次推理内 150 束几乎共享同一个
误差幅值（逐 run r 的中位数 0.012–0.273，远低于零均值噪声参考 0.592），但那份"水平"在不同种子/臂之间
相差 1.6–27×，池化后 MAD 把这份跨 run 散布算进来，r 升到 0.32–0.73（接近"随机"参考水平）。

⇒ **回答"偏移还是方差"**：H8 缺口的主体是**每个模型实例一个固定的量级错误**（同一模型内 12/13 项偏移主导，
非逐束随机涨落）；**其"随机"成分几乎全部来自训练实例之间的水平不稳定**，不是同一模型在不同束上的涨落。
因此"便宜校准"能救的是前者（而且必须按模型重标），救不了后者。

L2（门禁真正使用的口径）下的逐项结果与 oracle 上界：

| 口径 | 基线达标率 | 偏移主导项数 | oracle 校准后达标率 |
|---|---|---|---|
| **官方 H8**（joint 5 种子中位数） | 0.1318 | 12/13 ／ 13/13 | **0.9723** |
| 主分析（10 个 E1 run 种子中位数） | 0.3236 | 12/13 ／ 13/13 | 0.9928 |
| 站 1（joint 5 种子） | 0.1651 | 13/13 ／ 13/13 | 0.9974 |
| E2 输入档 1e5 | 0.2538 | 12/13 ／ 13/13 | 0.9626 |
| E2 输入档 3e3 | 0.2651 | 12/13 ／ 13/13 | 0.9908 |
| 对照：未路由的 independent 臂 @1e4 | **0.5174** | 12/13 ／ 13/13 | 0.9964 |

### 三条限定（决定"便宜"二字的实际含义）

1. **偏移是"每个训练实例一个常数"，不是普适常数。** 官方口径下 joint 臂 5 个种子的逐 run 中位误差水平
   max/min 比在 **1.6×（`m6_hf_energy_ratio_gap`）到 27.0×（`eps4d_rel`）** 之间，13 项中 11 项 ≥3.6×
   （逐项值见 `exp4_summary.json` 的 `offset_stability_across_runs`）；joint 与 independent 两臂
   相差最多 **4.5×**（`sigma_yy_rel`）。一套常数不能跨模型通用，只能按模型重标。
2. **校正方向不可从落盘产物得到。** `per_beam[].obs` 是幅值向量（`observable_vector` 对 M4 的 11 个分量与
   M5/M6 全部先取 `abs`，见 `metrics.sigma_errors` / `halo_fraction_gap` / `hf_energy_ratio_gap`），符号被抹掉。
   故本文的"偏移"是**幅值共同成分**；oracle 的 `|m − median(m)|` 在符号一致时等于真实校准残差，符号混杂时
   是残差下界 ⇒ **oracle 是达标率上界（且用了 test 信息），不是可达值**。
3. **13 个旋钮的联合可实现性未验证。** 观测量是同一张预测图的泛函，13 个独立的观测级修正常数不保证存在
   一个图像变换同时实现（M6 要细结构更多、M5 要晕更少，方向还需符号信息才能定）。

**可操作形式**：H8 缺口以"每个模型的固定水平错误"为主 ⇒ 最便宜的下一步不是重训，而是
(a) 落盘带符号的 13 分量、(b) 在 val 上标定每模型自己的 13 个常数、(c) 核对 val↔test 的水平一致性；
而"跨种子/跨臂水平散布 1.6–27×"属模型与数据层真改进（按模型重标常数也消不掉）。

## 5. 最差 3 项（官方口径按容差倍数）

1. **sigma_ypyp_rel**（竖直发散角 RMS σ_yp yp 的相对误差）：中位 0.028443，容差 0.007644，**3.72×**，
   通过率 0，r = 0.061，b/σ = 12.3（偏差份额 0.993）。竖直平面被一个几乎与束无关的固定量错开。
2. **sigma_yy_rel**（竖直 RMS 尺寸 σ_yy 的相对误差）：中位 0.024806，容差 0.007440，**3.33×**，通过率 0，
   r = 0.062，偏差份额 0.993。
3. **abs_delta_rho_y_yp**（竖直平面相关系数 ρ(y,yp) 的绝对变化）：中位 0.001145，容差 0.000346，**3.31×**，
   通过率 0，r = 0.181，偏差份额 0.942。该项的容差线是 13 项中最紧的（3.46e-4），"最差"同时来自紧容差
   与固定偏移；其 oracle 上界（0.687）也是 13 项中最低的。

次三名：`sigma_xx_rel` 2.67×、`abs_delta_rho_x_xp` 2.41×、`abs_delta_rho_x_y` 1.89×。
主分析口径（10 run 种子中位数）的前三名是 `abs_delta_rho_y_yp` 2.65×、`m6_hf_energy_ratio_gap` 1.86×、
`sigma_xx_rel` 1.83×（跨口径稳定的最差簇 = 竖直平面两项 + ρ(y,yp) + σ_xx + M6）。

主导成分：三项的 r ≤ 0.19（远低于 0.592），r 与 b/σ 都指向同一个无符号约束下的结论——误差幅值在
150 束上几乎恒定（`sigma_yy_rel` 逐 run 相对离散 r = 0.04–0.36，中位 0.10），主导成分是**共同水平**而非逐束方差。

`m6_hf_energy_ratio_gap`（六投影 σ_smooth=1 bin 高通能量比 |Δ| 的均值 = 细结构量）是系统成分最强的一项：
r = 0.011（10 个 run 全部落在 0.009–0.020），逐 run 中位误差 0.0350–0.0591，5 个种子的逐束模式相关
≥ 0.97——一个跨种子几乎不变的常数误差（0.054 ≈ 容差 0.029 的 1.85 倍）。

## 6. 地板参照：容差线本身是什么（裸子样本，1e5 档）

裸子样本（无模型）= 同一束 1e5 粒子随机子集相对 2e5 全量参照的 13 项 |Δ|，12 000 样本。

| 观测量 | 裸中位 | 裸中位/容差 | 裸符号偏差中位/σ | 模型中位/裸中位（官方） |
|---|---|---|---|---|
| sigma_xx_rel | 0.002554 | 0.348 | 0.018 | 7.7 |
| sigma_xpxp_rel | 0.002977 | 0.336 | 0.013 | 3.1 |
| sigma_yy_rel | 0.002630 | 0.353 | 0.013 | 9.4 |
| sigma_ypyp_rel | 0.002676 | 0.350 | 0.014 | 10.6 |
| abs_delta_rho_x_xp | 0.000050 | 0.011 | 0.000 | 214.4 |
| abs_delta_rho_x_y | 0.001734 | 0.345 | 0.005 | 5.5 |
| abs_delta_rho_x_yp | 0.001706 | 0.344 | 0.012 | 5.2 |
| abs_delta_rho_xp_y | 0.001573 | 0.340 | 0.011 | 3.7 |
| abs_delta_rho_xp_yp | 0.001573 | 0.339 | 0.015 | 3.3 |
| abs_delta_rho_y_yp | 0.000114 | 0.331 | 0.010 | 10.0 |
| eps4d_rel | 0.004187 | 0.345 | 0.021 | 1.6 |
| m5_halo_fraction_gap | 0.000140 | 0.530 | 0.000 | 3.5 |
| m6_hf_energy_ratio_gap | 0.027484 | 0.942 | **24.714** | 2.0 |

两条结论：

- 11 个 M4 分量的裸符号偏差 |中位|/σ ≤ 0.021 ⇒ **容差线确是一条抽样噪声线**（裸中位/容差 ≈ 0.34–0.35，
  与半正态的 0.6745/1.96 = 0.344 一致）。模型误差中位是这条地板中位的 3–10×（`abs_delta_rho_x_xp` 例外：
  地板中位近 0 而其容差线由裸分布尾部决定，模型/地板 = 214×）。
- `m6_hf_energy_ratio_gap` 例外：裸符号偏差中位 **+0.0275**、σ = 0.0011、|中位|/σ = **24.7** ⇒ 该档的 M6 容差线
  （0.02917）不是噪声线，而是 1e5 子样本自身的高通能量**系统偏差**（p95 ≈ 0.0275 + 1.6σ）。即 M6 的容差
  量级判定为「复现 1e5 子样本细结构水平的机械量级」，而非统计涨落；这条线的来历应在解释 M6 读数时单列。

## 7. 额外发现（直接影响 H8 读数的口径事实）

1. **臂路由无区分力**：`e1_gates.json` 的 H3 为 `joint_wins = 5, n_ties = 5, tied_at_domain_edge = true`
   ——两臂 val N_eff 全部钉在 1e5 域顶（上溢），"joint 胜"是域顶平局按字面规则计胜的结果。而 H8 只在
   joint 臂上评估：**同一 H8 口径换到 independent 臂 = 0.5174**（落在 0.5–0.8 区间 ⇒ 判「不可判定」），
   joint 臂 = 0.1318（判「不成立」）。逐 run 总达标率：joint 0.060/0.124/0.170/0.485/0.505，
   independent 0.363/0.405/0.603/0.606/0.725。
2. **种子中位数口径把"水平散布"变成"选档"**：`m6` 的 5 个种子水平几乎相同（逐束模式相关 ≥0.97）；
   `sigma_yy_rel` / `sigma_ypyp_rel` 的种子水平相差 7.1×/7.3×，且种子中位数向量与水平最高的种子
   相关最高（0.92 / 0.95）。逐 run 水平、与种子中位数的相关阵见 `exp4_summary.json` 的 `seed_selection`。
3. **均值 vs 中位数**：joint 逐 run 达标率均值 0.269、中位 0.170，H8 的中位数聚合给出 0.132
   （≤0.5 判"不成立"）；若改用逐 run 均值，joint 仍在"不成立"侧，independent 侧则进入"不可判定"。
   ⇒ H8 的"不成立"对 joint 臂稳健，但**对整个 Phase 1 结论不稳健**（换臂即换档）。

- **未做带符号的误差分解**：落盘产物无符号信息，本文的"偏移"是幅值共同成分；符号一致性与 val↔test
  水平一致性都未验证。定向验证只需用现有 `best_val.ckpt` 对 val/test 各跑一次推理并落盘带符号的 13 分量
  （无需训练、无需重评容差），即可判定"校正常数"是否真的存在且可迁移。
- **oracle 用 test 自拟合**：上界，不是可达值；亦未验证 13 个修正能否由一个图像变换联合实现。
- 未改动 `results/`、`data/`、`src/`（只读）；未触碰 GPU。
- `folded_fit` 假设同一观测量下 150（或 1500）个样本来自同一 (b, σ) 分布；跨束异方差会把额外离散计入 σ，
  使偏差份额偏保守。`r = MAD/中位数` 不依赖该假设，两套判据的逐项一致性列在 `exp4_summary.json`。
