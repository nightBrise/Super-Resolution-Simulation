# T0 实验5：不饱和度量下的跨站复测（站 0 → 站 1）

**范围**：line2 Phase 1 的 5 个 `e1_joint_s0..s4` run；尺子 = `test_eval*.json` 的逐束
M1（`per_beam[].err` = 20 个子样本 `group_rel_rmse` 的中位数），@ N_low = 1×10⁴、test 切分、
150 束、站 0 与站 1 由同一 `best_val.ckpt` 评估。重跑命令见文末。

## 1. 判定

**预注册第二条分支触发：存在可量化的跨站差异（|跨种子中位相对落差| = 7.36% > 5%，且 5/5
种子的配对 bootstrap 95% CI 排除 0）。但方向为负——站 1 的逐束 M1 系统性低于站 0，5 个种子
一致，150 束中仅 0–4.7% 的束在站 1 更差。就"退化/损失"的语义而言，实测是轻微提升而非损失。**

判定分支的落表依据（`exp5_summary.json` 的 `summary`）：

| 预注册条件 | 实测 | 是否触发 |
|---|---|---|
| CI 普遍包含 0 | 0/5 个种子 CI 含 0 | 否 |
| \|中位相对落差\| ≤ 5% | 2/5 个种子 ≤ 5%；跨种子中位 7.36% | 否 |
| CI 排除 0 且幅度 > 5% | 5/5 排除 0，跨种子中位幅度 7.36% | **是** |

## 2. 关键数字

逐 run（配对对象 = 同一 ckpt 的同一束，Δ = err_站1 − err_站0）：

| run | seed | err 站 0 | err 站 1 | 中位 Δ | 中位相对落差 | bootstrap 95% CI | Wilcoxon p |
|---|---|---|---|---|---|---|---|
| e1_joint_s0 | 100 | 0.254818 | 0.244437 | −0.008465 | −3.35% | [−4.00%, −2.73%] | 1.3×10⁻²⁵ |
| e1_joint_s1 | 101 | 0.281061 | 0.273902 | −0.006769 | −2.42% | [−2.79%, −2.07%] | 1.9×10⁻²⁵ |
| e1_joint_s2 | 102 | 0.266393 | 0.236621 | −0.030444 | −11.47% | [−11.74%, −11.21%] | 2.3×10⁻²⁶ |
| e1_joint_s3 | 103 | 0.225916 | 0.208691 | −0.016799 | −7.36% | [−7.75%, −7.09%] | 2.3×10⁻²⁶ |
| e1_joint_s4 | 104 | 0.263158 | 0.236336 | −0.026207 | −10.01% | [−10.32%, −9.76%] | 2.3×10⁻²⁶ |

跨 run 汇总：中位相对落差 **−7.36%**（范围 −11.47% … −2.42%），中位 Δ **−0.016799**
（范围 −0.030444 … −0.006769）；5 个种子中位 err **站 0 = 0.263158、站 1 = 0.236621**。

N_eff 溢出对比：两站 5+5 个 run 级 `n_eff` 全部 = 1×10⁵ / `overflow`，逐束溢出占比站 0 为
0.847–1.000、站 1 恒为 1.000——H7 的不可判定正是由两侧同时触顶造成，换尺子后同一对象可测。

## 3. 分母语境（同 M1 尺度）

绝对 err 本身不足以读"落差"的方向与份量：两站的可达误差刻度相差数倍。

| 量（M1 口径） | 站 0 | 站 1 | 站 1 / 站 0 |
|---|---|---|---|
| 裸输入（N_low = 1×10⁴，test 束） | 1.246739 | 1.244580 | 1.00 |
| 裸输入（N_low = 1×10⁵，test 束） | 0.285678 | 0.285552 | 1.00 |
| 零信息常数解（700 train 束均值图） | 0.194398 | 0.035212 | 0.18 |
| 跨束两两 M1 中位数（30 test 束 × 435 对） | 0.282306 | 0.051225 | 0.18 |
| 模型 err（5 run 中位） | 0.263158 | 0.236621 | 0.90 |
| 模型 / 常数解 | 1.35 | 6.72 | 5.0 |
| 模型 / 跨束差异 | 0.93 | 4.62 | 5.0 |
| 裸输入→常数解的区间闭合率 | 93.5% | 83.3% | 0.89 |

三条读法给出不同侧重的结论：

1. **原始 M1**（第 2 节，预注册判定所用）：站 1 略优 7.4%，两侧裸输入难度几乎相同
   （1.2467 vs 1.2446，差 0.17%），故该优势不是"站 1 的观测更容易"直接造成的。
2. **对常数解下限归一**：站 1 的残差是零信息解的 6.7 倍，站 0 是 1.35 倍——站 1 目标图跨束
   近乎同形（两两 M1 中位 0.051 vs 站 0 的 0.282），可达误差远低于站 0，模型在同一绝对误差
   水平（≈0.24–0.26）下于站 1 的残差要差得多。
3. **区间闭合率**：以"裸输入 → 常数解下限"为全程，模型在站 0 走完 93.5%、站 1 走完 83.3%，
   差 10 个百分点——站 1 的短板存在，但远不如第 2 条读法显得剧烈。

三者的分母含义不同（原尺度 / 残差倍数 / 区间闭合），本报告不替它们排序；"7.4% 无退化"这一
结论只在第 1 条读法下成立。参照噪声地板（1×10⁵ 档配对，两站池化标量）为 0.285597，与
`e0_curve.json` 的 `reference_noise_floor` 一致。

## 4. 范围与偏差

- **`e1_indep_*` 无站 1 产物**：`results/` 下带 `test_eval_station1.json` 的 run 只有
  `e1_joint_s0..s4` 五个（`scope.scan` 机读落盘）。E3 原设计只对获胜变体做跨站，独立臂与
  E2 十个 run 均为站 0 单侧。故本报告范围仅 joint 5 种子；补独立臂需重跑评估（GPU）。
- **训练消费两站 ⇒ 本对比不是迁移检验**：`train.py:104` 构造 `Line2Pairs` 时未传 `stations`，
  取 `data.py:47` 的默认值 `(0, 1)`，即站 1 的 train 束输入与目标同在训练集内（`10` [S5] 的
  test 束未见仅指束，不指站）。因此第 2 节的数字度量的是**站间性能一致性**，不是"把点 A 的
  能力外推到未见的点 B"；用户的 A→B 假设未被本实验检验。真正的 A→B 检验只需令训练取
  `stations=(0,)` 后在站 1 评估（`Line2Pairs` 已支持该形参）。
- **两站产物由不同 commit 产生**：站 0 的 `test_eval.json` 记 `code_version = b758e579`、
  站 1 记 `a7b3530c`。两 commit 之间 `src/line2/metrics/` 与 `src/line2/experiments/evaluate.py`
  的推理/度量路径逐字节相同（差异只新增 `m2_buckets` 报告字段），故 `err` 可比。
- **裸输入逐站值由解码得出**：`e0_curve.json` 只给池化值；逐站值按其「束 → 站 → 档 → 子样本」
  的展开次序解出；解码前提由脚本内 `verify_bare_decode` 用数据集重算 24 个点（4 束 × 2 站 ×
  3 子样本）核对，结果落于 `bare_reference.decode_verification`（`max_abs_diff = 0.0`，全等）。
- **常数解为复算**：站 0 复算与 `exp3_constant_control` 快照逐点相同（最大偏差 0.0），站 1 为
  本报告新增（同口径），只作分母语境、不参与判定。
- 站 1 目标图的跨束近乎同形（第 3 节第 2 条）是本报告顺带实测到的现象，未追因；若该现象属
  数据管线问题而非物理，会同时影响本报告与 Phase 1 的站 1 侧全部结论，值得单独核查。
