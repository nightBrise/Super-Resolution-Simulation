# 前置①：站 1 目标图「同形」查因（T0 待裁决第 4 条）

> 性质：Phase 1 交付后的诊断性分析（零训练、纯 CPU、只读 `src/`＋`data/`）。本目录全部产物为
> 诊断证据，**不是**预注册门禁输出；正式采纳任何口径变更须经 99 登记。
> 对象：`line2_ds_v1/test.h5` 的 150 个 test 束，站 0/站 1 的 `target_full`（各 200,001 粒子的
> 六投影 128² 直方图）及其逐束自定标 `bin_edges`。

## 0 判决

**判定：物理（主因，置信度 高 ≈0.85）——FODO 把每束的形状参数驱到饱和（ρ_x 站 0 的
−0.45…−0.59 → 站 1 的 0.99746…0.99760，跨束两两 |Δρ| 收缩 1106 倍）；「逐束自定标」标注口径
（spec `10` [S4] C4 明文设计）是共因——它恰好严格抹掉站 1 仅剩的两个可分辨维度（踢角平移与
0.65–0.78% 的束尺寸差）。既非管线缺陷，也非度量伪影。**

三条分支的逐条对表见 §6。要点：

- **不是缺陷**：150 束 × 2 站的 `target_full` 与 `bin_edges` 由现行代码 + 锚点**逐位复现**
  （计数最大绝对差 = 0，edges 逐位相等）；h5 抖动 attrs 与生产派生器 0 处不符；抖动确为该束
  自己的、作用在自己 FODO 入口前（`transport.py:150` → `:155`）。粒子层差异**没有**大于直方图
  差异（缺陷判据的反向）。
- **不是度量伪影**：把逐束自定标换成任何「只留形状」的公正常规（σ 对齐 + 公共网格，V2c），
  塌缩原样保留（0.2144 → 0.0371，比值 0.173，与生产口径 0.185 同量级）。V2/V2b 口径下 M1 确实
  恢复（比值 1.00 / 0.81）——但那是把**尺寸与位置**通道重新纳入度量，不是纠正了度量。
- **是物理**：理论（同一套映射 + 同一套分箱、同协方差高斯锚点）预测收缩比 3.44×，观测
  5.41×，比值 **1.58× < 2×**（预注册「同一量级」阈）；粒子表协方差与解析 Σ 一致到 2×10⁻¹⁵。

**顺带确证的一个结构性事实（对设计有独立价值）**：三个抖动旋钮里振幅最大的踢角 θ（±10 µrad =
±0.58σ_x′；单步 ±5 µrad 即 0.29σ_x′）在生产 `target_full` 图上**严格不可见**（单旋钮
M1 = 0.0000，浮点级），因为它是纯平移、而逐轴 min/max 自定标对平移严格不变；同一改动在公共域
口径下 M1 = 0.74–0.81。即：束群的形状多样性实际只由 δ（薄透镜 ±5%）与 ℓ（漂移 ±1%）提供，
θ 是"死旋钮"。

## 2 第 2 层：理论层（判决性）

### 2.1 共同 FODO 的 4×4 传输矩阵（生产同一条 ocelot 实算路径）

```
R (行/列序 x, x', y, y')                 det R = 1.0000
[ -1.8782225   4.2625590   0          0        ]   x 块奇异值 [4.6650, 0.21436]
[ -0.2990089   0.1461717   0          0        ]   y 块奇异值 [1.57176, 0.63623]
[  0           0          -0.6013505  1.0703789]
[  0           0          -0.2990089 -1.1307003]
```

cell 相位推进实算实测 75.0000°（`10` [S3] C1 ✓）；cell 起点匹配 Twiss β=8.525 m、α=−2.024。
而束的实际 β：站 0 = 23.49–23.52 m、α = +0.507…+0.740；站 1 = 91.96–96.00 m、α = −14.39…−14.01
（**约 11 倍于晶格匹配 β**）→ 束相对晶格是**大幅失配**的，在晶格内始终远离束腰，这就是 ρ 饱和的物理来源。

### 2.2 Σ 传播（解析）与粒子表对照

Σ₀ = J_i Σ_anchor J_iᵀ（J = 漂移+薄透镜的精确线性映射），Σ₁ = R Σ₀ Rᵀ。与 150 束粒子表实测协方差：

| 站 | 解析 Σ vs 粒子表 Σ 最大相对误差 |
|---|---|
| station0 | 1.8×10⁻¹⁵ |
| station1 | 2.0×10⁻¹⁵ |

（踢角只改均值不改 Σ；实测 ε_x 跨束跨站恒定 4.9634×10⁻⁹，与辛性一致。）

### 2.3 形状参数（判决核心）

| 量 | 站 0 | 站 1 |
|---|---|---|
| ρ_x = σ_xx′/√(σ_xx σ_x′x′) | 中位 **−0.5340**，域 [−0.5949, −0.4523] | 中位 **+0.99753**，域 [0.997463, 0.997595] |
| 跨束两两 \|Δρ_x\| | 中位 **4.369×10⁻²**（p95 1.17×10⁻¹，max 1.43×10⁻¹） | 中位 **3.949×10⁻⁵**（p95 1.06×10⁻⁴） |
| α_x | +0.507…+0.740 | 中位 **−14.216**，域 [−14.394, −14.011] |

**收缩比 = 4.369×10⁻² / 3.949×10⁻⁵ = 1106 倍。** 机制可解析：α 饱和区
dρ/dα = −(1+α²)^{−3/2}，α₁=−14.2 处为 −4.3×10⁻⁴，故 δ 引起 Δα₁=0.38 只换成 Δρ₁=1.5×10⁻⁴。

**为什么站 1 是饱和点**：自定标图组对高斯形态而言只由 ρ 决定（逐轴 min/max 定标 ≈ 逐轴 σ 定标），
而 |α|→∞ 时 ρ→±1 且 dρ/dα→0。晶格周期扫描（`pre1_analysis.json: lattice_period_scan`）显示
**这不是 2-cell 的巧合**：1/2/3/4/6/8 cell 的 Δρ 收缩比分别为 1638× / 1106× / 150× / 2830× /
2635× / 686×——**本晶格各相位的形状都饱和**（因束始终严重失配），挪站不解决问题。

### 2.4 理论 → 观测（把收缩比翻译到 M1 单位）

以「同协方差高斯锚点 + 生产同一套 J_i / R + 生产同一套 `station_edges`+`six_projections`」
复算 150 束两站图组的逐对 M1（`pre1_theory_images.py`）：

| | 站 0 中位 M1 | 站 1 中位 M1 | 收缩比 |
|---|---|---|---|
| 理论（高斯锚点） | 0.19120 | 0.05566 | **3.44×** |
| 观测（真实锚点，V1 生产口径） | 0.26017 | 0.04808 | **5.41×** |
| 理论/观测比值 | | | **1.58×** |

→ 预注册的「理论收缩比能解释观测的大头（同一量级、比值在 2× 内）」**成立**。

## 3 第 3 层：粒子层（全 150 束，非抽样）

差异分解（跨束两两中位；位置 = \|Δμ\|/σ̄，尺寸 = \|Δlnσ\|，形状 = \|Δρ\|）：

| 通道 | 站 0 | 站 1 |
|---|---|---|
| 位置 Δ/σ̄：x / x′ / y / y′ | 4.9e−8 / **0.349** / 9.2e−8 / 0.095 | 0.0375 / 0.0085 / 0.0436 / 0.0385 |
| 尺寸 \|Δlnσ\|：x / x′ / y / y′ | 2.2e−4 / 0.0320 / 2.2e−4 / 0.0165 | 0.0065 / 0.0015 / 0.0078 / 0.0069 |
| 形状 \|Δρ\|：ρ_x / ρ_y | **0.0437** / 9.6e−4 | **3.95e−5** / 3.96e−5 |

读法：

- 站 0 的束间差异**几乎全部来自形状**（|Δρ_x| 中位 0.044），位置在 x/y 上可忽略（ℓ 只通过
  漂移把 x′ 的一小部分搬进 x），尺寸在 x/y 上 2.2×10⁻⁴；x′ 的位置差 0.349σ 完全来自踢角。
- 站 1 的束间差异**只剩位置（3.8–4% σ）与尺寸（0.15–0.78%）**，形状塌到 3.95×10⁻⁵。
- ⇒ **粒子表在两站都按同一方式塌缩（形状塌缩），不是「粒子表差异大而直方图无差异」**
  （后者才是分箱伪影的指纹）→ 缺陷分支不成立。

## 4 第 4 层：度量伪影专项

### 4.1 站 1 的 edges 有没有互相趋同？——没有

逐束窗口（该束该站全量表逐轴 `[min,max]`）跨束统计（`pre1_edge_domains.json`）：

| 站 | 窗口宽度相对散布 (std/mean)：x / x′ / y / y′ | 窗口中心 std/宽度：x / x′ / y / y′ |
|---|---|---|
| station0 | 2.2e−4 / 6.2e−3 / 2.2e−4 / 1.7e−2 | 4.4e−7 / 2.3e−2 / 5.2e−6 / 9.0e−3 |
| station1 | 6.3e−3 / 1.5e−3 / 7.6e−3 / 6.7e−3 | 3.5e−3 / 7.8e−4 / 4.1e−3 / 3.6e−3 |

站 1 的窗口散布与站 0 **同量级**（0.15–0.76% vs 0.02–1.7%），没有"趋同"到同一域。
站 1 各束窗口宽度比站 0 大（x ×2.00、x′ ×4.31、y ×0.415、y′ ×2.81，见
`pre1_edge_domains.json: width_ratio_s1_over_s0`）——即站 1 的束整体变了形，但逐束仍是自定标的。

### 4.2 四种分箱口径的逐对 M1（150 束 × 11,175 对）

| 口径 | 站 0 中位 | 站 1 中位 | 站1/站0 | 该口径保留什么 |
|---|---|---|---|---|
| **V1 生产**（逐束 min/max） | 0.2602 | 0.0481 | 0.185（5.41×） | 形状 |
| V2 公共域（150 束池化 min/max） | 1.8250 | 1.8205 | **0.998** | 位置+尺寸+形状 |
| V2b 公共域、逐束去均值 | 0.3523 | 0.2859 | **0.811** | 尺寸+形状 |
| V2c 逐束 σ 标准化 + 公共网格 | 0.2144 | 0.0371 | **0.173（5.79×）** | 形状 |

- **V2c 是伪影假设的直接对照**：它与 V1 的唯一区别是"用 σ 标准化代替 min/max 标准化、格子对齐"，
  两者都严格抹掉平移与尺度。塌缩原样保留（0.173 vs 0.185），且两站绝对值与 V1 各自同量级
  （站 0：0.214 vs 0.260；站 1：0.037 vs 0.048）→ **塌缩发生在形状通道里，不是分箱格子造成的**。
- V2/V2b 的"恢复"是因为把**尺寸（0.65–0.78% rms）与位置（3.7% σ，来自 θ 踢角）**重新纳入度量，
  即换了被测量对象，不是纠正了度量。注意 V2 的绝对值不可与 V1 跨站横比：站 1 的图是窄条纹
  （ρ=0.9975 ⇒ 长短轴比 1:28），同样的亚 bin 位移在条纹上产生远大的 M1 响应。
- 常数解（留一均值图）核对 exp5：站 0 = 0.19515（exp5 0.194398）、站 1 = 0.03512（exp5 0.035212）
  ——**与 exp5 独立复算一致到 0.4%**；且站 1 满足 0.0481 ≈ √2×0.0351（= 0.0496），即站 1 的目标集
  可读作"一张固定图 + 独立小扰动"。

## 6 与预注册判据逐条对表

| 分支 | 预注册条件 | 实测 | 是否触发 |
|---|---|---|---|
| 物理 | 理论收缩解释观测（比值在 2× 内） | 理论 3.44× vs 观测 5.41×，比值 **1.58×** | **是** |
| 物理 | 粒子表一致塌缩 | 粒子层 \|Δρ_x\| 中位从 4.37e−2 → 3.95e−5（同一 1106× 收缩） | **是** |
| 物理 | 管线审计无异常 | 逐位复现（计数差 0）、抖动 attrs 0 处不符、edges 逐束自定标 | **是** |
| 缺陷 | 审计发现抖动/传输/快照错误 | 无 | 否 |
| 缺陷 | 粒子表差异显著大于直方图差异 | 反向：粒子形状差异与直方图同步塌缩 | 否 |
| 伪影 | 固定公共 edges 后两两 M1 恢复到与站 0 同量级 | V2 1.825/1.820（1.00）、V2b 0.352/0.286（0.81）→ **字面触发** | **字面触发，但不成立** |

**冲突解析（这就是本报告的判决表述）**：伪影分句的字面条件在 V2/V2b 下确实成立，但这两条口径
改变了被测量的对象——它们把站 1 的**尺寸与位置**通道（真实存在、由 θ 与 δ 提供）重新计入，
而 V2c（只留形状、同样去掉平移与尺度）证明形状通道的塌缩在任何等变常规下都原样保留。
故归因为：**物理（形状参数饱和）为主因，逐束自定标目标口径为共因**；「伪影」读法只在其
字面口径（公共域）下成立，不构成对数据/管线的否定。

## 7 局限

1. 本报告的"形状"论证以二阶矩 ρ 为核心。图组并非严格高斯（锚点峰度 x 0.92 / x′ 2.56），
   站 1 的残差 M1（0.048）里含高阶结构与离格效应；理论→观测桥用高斯锚点近似，站 0 的理论值
   偏低 27%（0.191 vs 0.260），站 1 偏高 16%（0.056 vs 0.048）。判据只用到比值（1.58×）。
2. V2 的绝对值受"池化域宽于单束域"影响、且站 1 图为窄条纹，跨站不可直接比绝对值，只比比值。
3. 束 0（无抖动基准）落在切片 train 内，test 集不含 σ→0 极限束；抖动族的"名义点"由
   f_j=10 m 的强透镜主导（把 α 从锚点的 −1.648 翻到 +0.60），因此抖动族并非锚点的微小邻域。
4. 全部结论只覆盖 test 切分 150 束与 `line2_ds_v1`；train/val 由同一管线生成（同构结论可推，
   未逐位复算）。
